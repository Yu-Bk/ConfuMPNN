## 5 结论（v2 主结论）
1. **三类均衡覆盖成立**：配体 v2 = 酸 1CGE(−11.7) / 中性 1BJ4(+0.4，补入) / 碱 5O60_E(+11.2 RNA 结合)。route B（v14 clean per-protein 校准）mean 口径：1CGE 5/5（dev≤0.89）、1BJ4 **5/5（dev≤0.69）**、5O60_E 3/5（native/p2 dev −2.1 略超阈）→ **5O60_E 现场小样本标定（slope 1.65/−1.09）救回 native/p2（dev −0.77/−0.37）**。三类全部达标的前提是正确校准。
2. **中性补入改变 v1 印象**：v1 配体集 {5O60_E,1CGE,2FEO} 缺 native≈0 中性，且"难"位由 2FEO 承担（校准后仍 0–1/5）。v2 用 1BJ4(+0.4) 补中性后 per-protein 校准 **5/5 全中**——证明"难"是 2FEO 蛋白特异（高电荷方差），不是中性类别问题。此前"配体无中性"是纯覆盖缺陷。
3. **增益集中于极端臂**：1CGE p8/n8 +0.34~+0.45；5O60_E n8 +0.34、native/p2/n2 +0.29~+0.31。5O60_E 裸 A native±1=0（RNA 结合强正偏，bare mean +26.7 vs native +11.2）→ 条件化每序列命中从 0 提到 0.29–0.34，是 exp1 净增益最大处。
4. **per-seq 弥散大、bias 更紧**：encoder route B per-seq |dev|≤2 0.24–0.45；bias-only route C 0.52–0.92（5O60_E 0.52–0.71、1CGE/1BJ4 0.76–0.92）。**组成代价相反**：encoder 普遍删减带电残基（cr 0.36–0.94），bias 堆叠带电残基（cr 0.99–1.60）——两者都偏离 native 组成、方向相反。
5. **与蛋白模式 exp1 v2 同构**（跨模式结论一致）：裸 backbone 分布中心蛋白特异且常远离 native；条件化把分布均值搬到 target；极端臂增益最大；均值可控但单序列弥散大；表外/高增益蛋白需现场小样本标定；bias-only 逐序列命中全面强于 learned encoder（电荷单指标上）。
