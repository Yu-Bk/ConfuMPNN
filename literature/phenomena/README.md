# phenomena — 常见实验现象与意外现象

本目录记录论文中的**常见/预期现象**与**意外现象**，以及作者如何尝试解释或解决。意外现象往往是理解方法深层原理的关键。

## 意外现象（反直觉、值得挖）

### 1. 原生序列自身折叠预测反而差（P1）

- **现象**：myoglobin 原生序列单序列（无 MSA）AF2 预测 pLDDT=50.6、Cα RMSD=7.5 Å——即「天然蛋白」在这个严格设定下折叠预测很差；而 ProteinMPNN 设计序列反而 pLDDT>85、RMSD<1.0。
- **含义**：进化序列依赖共进化/MSA 信息折叠，脱离 MSA 后预测差；而 MPNN 设计序列是「结构自洽」的。→ 这解释了为何 MPNN 序列对骨架的折叠更确定。

### 2. 不动活性位点，活性却大幅提升（P1）

- **现象**：TEV 活性位点全部固定，仅远端突变，kcat/Km 却提升最高 26 倍、Km 下降 2–3 倍。
- **解释尝试**：远端突变通过**稳定 catalytic 构象态 / 全局刚化 loop**提升活性。微秒 MD 显示设计变体 loop 普遍刚化；115–124 区段刚化程度与活性正相关；Cys-His dyad 催化态布居（d_N-SH）下降最少的是活性最高的 hyperTEV60。
- **意义**：证明「无需显式功能设计，稳定化本身就能提升功能」——这是 P2/P3 用 pLDDT 等结构代理当奖励信号的深层依据。

### 3. EnhancedMPNN 更偏好带电残基、压低 A/S/T（P2）

- **现象**：ResiDPO 微调后，E/K/R 增多，A/Q/S/T 近 50% 被替换，P/G 几乎不动；A 在 de novo 骨架中尤其减少。
- **解释尝试**：A/S/T 在「埋藏/暴露」上语义模糊（都可在表面或核心），而 G/P 有独特构象偏好（G 可采取其他残基不可达构象、P 限制构象子集）故清晰。→ 本质是**降低序列-结构映射的模糊性**，从而提升 AF2 置信度。

### 4. 直接加 EP 目标并不能显著提升进化合理性，但能当「正则器」（P3）

- **现象**：MoMPNN 显式加入 Evolutionary Perplexity(EP) 目标，EP 本身不显著降低；但它一致地改善**其他非目标指标**。
- **解释**：EP（ESM 伪似然）作为正则器，与 TM 或 IG 互补，抑制模型偏离自然序列分布。→「看似无效的目标其实是好的正则器」。

### 5. 更高 AAR ≠ 更高可设计性/可开发性（P3）

- **现象**：氨基酸恢复率（AAR）与 designability/developability 不相关（Table 1 里高 AAR 的模型开发性反而不一定好）。
- **意义**：直接印证 P2 的核心论点（sequence recovery 是错位目标），把评价重心从 AAR 转向 designability + developability。

### 6. Weighted-score DPO 会「塌缩到单一指标」（P3）

- **现象**：把多目标合并成加权单分数的 Weighted-score DPO，在 Evo. ppl 上最优，但 RMSSD/TM/pLDDT/AAR 全面退化；且随迭代轮数增加收敛到单一指标，第 6 轮后 IG 开始下降。
- **解释**：单分数标量化导致优化方向被单一目标主导，无法平衡多目标。→ 这正是 ProtAlign 用「自适应 margin」而非「加权合并」的动机。

### 7. 昂贵的精确预测器在训练期「不可行」，须降级（P4）

- **现象**：netMHCpan 在线调用训练期太慢，被迫用 PWM 近似。
- **解决**：训练期用 PWM（300 万肽预标注一次），评估期回归精确 netMHCpan。→ 是「训练/评估解耦 + 近似」的通用工程现象。

## 常见（预期）现象（可作为方法论基准）

1. **固定位点越多，表达越高但活性可能受损**（P1）：TEV「无进化约束」设计表达高但无活性；「固定 50% 保守位点」达最佳活性。→ 固定位点是表达/功能的权衡旋钮。
2. **稳定性与功能通常负相关**（P1 引言）：进化优选功能而非稳定，天然蛋白普遍表达差/稳定性差——这是本文出发点。
3. **骨架重塑成功率与重塑区大小相关**（P1）：更激进的 EF+CD loop 重塑，heme 结合高温保留率更高，但也引入更大 Cα RMSD 偏差（CD-loop 1.51 Å）。
4. **高 pLDDT 序列稀缺**（P2）：当前 PSD 模型生成 pLDDT>80 的序列很少，导致 Application Sampling 偏好对数据不足。
5. **DPO 微调会牺牲序列恢复（seq recovery）**（P2）：RPL 单独用 seq recovery 掉到 54.23%，靠 RCL 拉回 55.56%——但这是「可接受」的代价，因为 recovery 不是目标。
6. **结构预测器相关性**：pLDDT 与 Cα RMSD 强相关（P2 Fig.6），使 pLDDT 可作为廉价设计性代理。

## 遗留问题（作者未解决/未来方向）

- P2：高 PAE 结果仍多，需更定向的 PAE 优化；EnhancedMPNN 尚缺实验表征。
- P3：缺湿实验验证；多目标内的「动态 margin」会不稳定，留作未来。
- P4：PWM 只覆盖单一基因型（b69bb1），多基因型泛化需扩展。
