# pattern — 跨论文规律与工作量分析

本目录记录从四篇论文中提炼的**可复用规律**与**工作量分析**（哪些环节最耗时/最昂贵，训练与湿实验分别怎么投入）。

## 规律提炼（跨论文通用模式）

1. **「序列恢复」是被广泛承认的错位目标**。P2 开宗明义点出 sequence recovery 与 designability 相关性弱；P3 明确指出「更高 AAR 不代表更高可设计性/可开发性，实践中更该关注后者」。→ 做 PSD 工作时应淡化 AAR，量化 designability。

2. **结构预测器的置信度（pLDDT/TM/pTM）是标准化的「客观奖励」**。四篇论文（尤其 P2/P3）反复用 AF2 pLDDT 或 ESMFold TM-score 作为无需湿实验的廉价、客观、逐点/逐残基的质量信号。→ 这是 DPO/RL 对齐到蛋白设计的关键突破口。

3. **「固定功能位点保留功能」是普遍前提**。P1 用 7 Å 第一壳层 + 保守位点固定；P2/P3 酶设计 benchmark 都固定催化残基；P4 在去表位同时要保结构。→ 任何「改序列」方法都要先想清楚「什么不能动」。

4. **DPO 微调是 ProteinMPNN 系模型的通用后处理**。P2/P3/P4 三条独立团队不约而同选 DPO（而非 PPO/RLHF），因为它简单、无需显式奖励模型、可离线。→ DPO 已是蛋白序列设计对齐的默认工具。

5. **昂贵预测器 → 廉价近似，是训练加速的通用套路**。P4 用 PWM 近似 netMHCpan；P2 用 pLDDT Accuracy 近似全 AF2 评测。→ 训练期的性质打分必须「够快」，精确版留到评估期。

6. **采样温度的双角色**：训练/rollout 用高温（1.0 或 τ 更高）鼓励多样性，评估/设计用低温（0.1）追求质量。P2/P3 一致采用。→ 是蛋白质生成模型的标配套路。

7. **数据防泄漏三件套**：结构聚类（30% 序列同一性或时间切分）+ TM-score mask（P4）+ 时间切分（P2 用 2021-09-30 后结构做验证）。→ 蛋白数据集尤其要防「同源序列泄漏」。

## 工作量分析（最贵环节）

| 环节 | 哪篇提及 | 相对成本 | 说明 |
|------|----------|----------|------|
| AF2 结构预测（全数据标注） | P2 | ⭐⭐⭐ 很高 | 每个 backbone 生成 8 序列 × AF2 预测，是 P2 最大的算力投入 |
| 全 AF2 评测（benchmark） | P2 | ⭐⭐⭐ 很高 | 酶 1000 骨架 × 8 序列 × AF2，因此才发明 pLDDT Accuracy 代理 |
| 在线 reward 调用（RL） | P3 | ⭐⭐ 高 | 纯在线 RL 昂贵不稳定，P3 用半在线解耦降低 |
| netMHCpan 在线调用 | P4 | ⭐⭐⭐ 很高 | 「太慢」，故改用 PWM（300 万肽标注一次） |
| 湿实验表征 | P1 | ⭐⭐⭐ 高但有限 | P1 只测几十~144 变体（vs 定向进化大面积筛库），是「计算替代实验」的价值所在 |
| DPO 微调本身 | P2/P3 | ⭐ 低 | P2: 2×L40, lr5e-7, 100k iter；P3: 8×4090, 20 轮。相对结构预测便宜 |

### 数据效率规律（P2 独家发现）

- ResiDPO 用 **1000 个 backbone** 就能达到 DPO 用 **19000 个**的 pLDDT accuracy（63.44%）。
- 且「502 个精心挑选（δ=10 过筛）的 backbone」即可获显著提升。→ **残基级监督在低数据域显著更高效**，这对「湿实验数据昂贵」的性质优化（如 P2 提到未来扩展到稳定性/表达）很有意义，暗示 DPO 对齐对稀缺湿实验数据特别友好。

### 超参数铁律

- pLDDT > 80 = 广泛接受的「足够可设计」阈值（P2 据此设 β=80）。
- 酶设计成功判定：pLDDT>80 + Cα RMSD<1.5Å（P2）；binder：pLDDT>80 + PAE<10 + RMSD<1Å（P2）/ <2Å（P3）。
- MHC 递呈 rank 阈值：2%（弱结合）vs 0.5%（强结合）（P4）。

## 四篇的「可迁移组件清单」

提供一个可复用到未来项目的积木清单（详见各 innovation 笔记）：

5. Relative Sampling（δ=10）偏好对构造（P2）

7. 自适应 margin 多目标 DPO（P3）
8. 半在线 rollout→标注→训练循环（P3）
9. PWM 近似昂贵性质预测器（P4）
10. 可见性/表位去重计数定义（P4）
