## 总结论（是否产出合理可控序列）

**1. 电荷方向可控且单调，但 global 校准下幅度系统性过冲。**
两模式生成电荷均值都随 target 6.87→12 严格单调上升：蛋白 9.36→15.56、配体 10.02→17.00；
线性响应斜率 >1（蛋白 1.27，配体 1.32），target Δ=+5.13 → 实测 Δ=+6.2(蛋白)/+7.0(配体)。
L11 不在任何校准表内，回退 global 校准后仍普遍过冲：dev 均值 蛋白 +2.3~+3.6、配体 +3.2~+5.0，
`|dev|≤2` 命中率 蛋白 23–29%、配体 18–28%（配体高 target 最差）。
→ 在表外蛋白上**精确电荷控制需 per-protein / 现场小样本标定**（v12.2 已确立：标定后可达 ~70%+）；本实验的"可控"结论限定在**单调方向正确 + 高 target 幅度偏大**这一档。

**2. 固定界面位完全保留（硬约束满足）。**
10 个固定位（I3 I5 I9 I34 I35 I89 I124 I131 I134 I135）在全部 2400 条中 100% 等于 native，逐条全对率 100%。

**3. 结构/性质总体合理但折叠置信中等。**
- pLDDT 均值 54–56（native 76.9）；TM(vs native 骨架) 0.60–0.67（native 自身回折 0.794），TM≥0.7 占比 蛋白 29–39%、配体 17–20%。→ 序列能部分折叠回 L11 拓扑但置信低于 native（高突变 + 正电富集所致）。
- 蛋白模式：Tm 55.1→58.5°C、Sol 78.8→81.9% 随 target 略升；配体模式：Tm 53.8–54.8°C 基本平稳、Sol 94–95%（≈native 94.6%，反映配体上下文/组成差异）。
- 回收率整体 ~27%、非固定 ~22%（正电目标需大量引入 K/R，删改剧烈）。

**4. 模式差异小结。**
蛋白模式折叠略优（TM 高 ~0.04）但 Sol 较 native 低 ~14 个百分点；配体模式电荷过冲更严重（高 target dev +5.0）且折叠稍弱，但 Sol 贴近 native——两模式在"电荷可设计"上同向，均需标定才能收紧命中。
