- 固定位 100% 保留；回收率≈27% 与 global 相当；pLDDT/TM/RMSD/Tm/Sol 未见系统性变化 → 校准只改电荷条件，不改折叠/性质分布。


## 结论
- **治增益**：现场小样本标定把两模式各 target 的电荷均值 dev 从 global 的 +2.3~+5.0 压到 +0.3~+1.1，证明 L11（表外高 pI）自身响应的 slope/intercept 可被 50 条探针可靠捕获（LOOCV 蛋白 0.6、配体 2.5，均<3）。
- **不治散布**：std≈4–5 不变，`|dev|≤2` 命中率虽提升（蛋白 31–34%、配体 29–41%），但仍远低于 100%——单序列散布由 encoder/生成侧弥散决定，标定无法消除。
- 折叠/稳定/可溶（pLDDT≈54–56、TM≈0.6–0.67、Tm≈54–58°C、Sol 蛋白≈79%/配体≈94–95%）与 Exp2(global) 基本一致，即校准不影响除电荷外的设计性质。
