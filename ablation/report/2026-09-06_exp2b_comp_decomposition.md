> 归属：ablation/（受控消融，exp2 组成侧补充，S2，CPU）。对照 exp2 电荷命中报告：`ablation/report/2026-09-06_exp2_{prot,lig}_bias_vs_encoder.md`。

> 逐蛋白逐臂完整表：`output/exp2_comp_decomposition_tables.md`；机器可读：`output/exp2_comp_decomposition.json`。

## 1 科学问题
exp2 已证 bias(route C) 的电荷命中强于 encoder(route B)，但代价是组成畸变（C cr>1 膨胀、B cr<1 删减）。
本报告把"电荷总量怎么变的"拆成 **加带电残基(膨胀) / 删带电残基(删减) / D,E↔K,R 对侧置换** 三部分，
并回答：两种偏差是**同号膨胀 vs 同号删减**、还是互相抵消？是否其实都少做了"同号（数量不变）置换"？

## 2 定义与方法
- 逐位比较设计序列 vs native（同骨架同长）：charged = {D,E,K,R}（含 N/C 端电荷的组成口径，不含 H，同 exp2 cr）。
- **膨胀 add**：native 非带电 → 设计带电；**删减 del**：native 带电 → 设计非带电；
  **置换 flip**：native D/E → 设计 K/R（flip_neg2pos）或 native K/R → 设计 D/E（flip_pos2neg），即对侧电荷交换；
  **同号置换 same_sub**：D↔E 或 K↔R（改变序列、不改变 D/E、K/R 计数）。
- 每设计序列统计事件数 → 逐臂/逐蛋白求均值。`cr = 设计带电总数/native带电总数`；
  Δtotal_charged = add−del；Δpos(KR) = 设计 K+R − native K+R；Δneg(DE) 同理。
- 每设计序列相对 native 的序列一致率 rec 一并列出。
- route 映射：prot `B=route_B`（encoder+per-protein 校准）、`C=route_C`（bias，lookahead 0.5）、`A=route_A`（裸 pool）；
  lig `B=routeB_cal`、`C=routeC`、`A=routeA`。B/C 逐 5 臂；A 只有全 pool（裸 backbone 无臂概念，作为蛋白级参照）。

## 4 关键观察
1. **encoder(B) = 同号对称删减**：cr 0.54–0.63，事件空间 ~62–68% 是删减、仅 ~24–28% 加、
   ~6–12% 置换。且**删减不挑符号**——Δpos 与 Δneg 同负、量级几乎相等（如 1AZM Δpos −11.2/Δneg −10.7；
   5O60_E native 臂 Δpos −12.7/Δneg −10.7）。净电荷偏移来自删两个符号时**极小的不对称**：
   net 偏移 ≈ Δpos−Δneg（5O60_E native 臂 = −2.0，即 dev −2.1 的来源）。即"把大量带电残基删掉、
   靠删谁更多一点来调净电荷"——与项目记忆"模型无差别删带电残基总数、靠不对称删减调净电荷"直接吻合。
2. **bias(C) = 同号对称膨胀**：cr 1.18–1.50，事件空间 ~53–65% 是加、~19–36% 删、~11–19% 置换。
   Δpos 与 Δneg 同正、量级接近（如 1BJ4 native 臂 Δpos +24.4/Δneg +25.3）→ 把带电残基大量加上去、
   靠加谁更多一点来调净电荷（net ≈ Δpos−Δneg = −0.9，而 target native 0 附近 mean dev ~0.01）。
3. **裸 backbone(A) 本身已中度畸变**：cr 0.88–1.43、frac_add 0.39–0.61、frac_del 0.22–0.56。
   条件 encoder 是在裸 backbone 畸变之上**进一步加重删减**，bias 是在其上**进一步加重加**。
4. **两者都不做"数量守恒的对侧置换"**：flip（D/E↔K/R）占比只有 0.06–0.19，same_sub（D↔E/K↔R，
   只改序列不改计数）却高达每条 9–53 处。要在**保持带电残基总数(cr≈1)的同时**把净电荷搬到 target，
   最干净的机制本应是"删一个对侧电荷→加一个同侧电荷"或直接 D/E↔K/R 翻转；两条路线都绕过它，
   改用直接增删带电残基（cr 大幅偏离 1），把净电荷做成**两个大数的差**，故对组成稳定不利。
5. **"两种偏差可互相抵消吗？"——只在总数层近似抵消，机制上不抵消且不保序**：
   B 把带电总数砍到 ~0.6×、C 把带电总数抬到 ~1.3–1.5×，二者若按计数相加恰好回到 ~native 附近；
   但 B/C 是在**不同位置/不同种子**上加删的（native 回收率 B≈0.34–0.53、C≈0.39–0.60，
   与裸 backbone 相当甚至更高），位置层面不会复原 native，cr 的抵消是聚合假象。
   真正能同时满足"净电荷贴靶 + 带电总数≈native"的同号置换路径被两种机制都少做了。

## 5 结论（exp2b）
- encoder 的组成代价是**对称删减**（cr≈0.6，K/R 与 D/E 一起删），bias 的组成代价是**对称膨胀**
  （cr≈1.3–1.5，K/R 与 D/E 一起加）；两模式的净电荷控制都只是"两个大数之差"里的小不对称。
- 两条路线都少做"数量守恒的对侧置换"（flip 仅 6–19%），说明把"带电总数"与"净电荷"解耦的
  干净手段未被使用——这解释了为什么电荷命中虽高但组成必然偏离 native。
- 对模型设计的含义：若要在不伤带电总数的前提下控净电荷，监督/引导应鼓励 **flip（同数对侧置换）**
  而非直接增删；这与 v12 系列"删减捷径"及配体 v14 "删减定向口袋"的既有诊断相互印证
  （根因都是模型用增删总带电残基数来凑净电荷）。
