## 二、口径框架修正（用户核心方法论决策）

## 五、72% 判据是循环参照（用户质疑成立）

- `index/DESIGN_CRITERIA.md`：H2 科学判据 = **单臂 |实际电荷−target| ≤ 2.0**（无整体百分比阈值）
- `index/PROJECT_LOCAL_V12_2.md` L201："判据：… H2 ≥ **当前 72%**"——72% = v12.2 per-protein 实测 36/50 被挪用为后续版及格线

## 六、v12.3 校准表不准根因 + 新方法

build_calibration.py：per_protein=各蛋白自身诊断拟合；global=**合并全部诊断蛋白(target, mean)点重新线性拟合**（跨蛋白平均）。

v12.3 校准表：global slope 1.471 / intercept −5.935（intercept 深负 = 模型 target=0 时系统性偏负）。per slope 分布 0.97–2.01（差 2 倍）。

**不准根因**：
1. **响应非线性（S 弯曲）**：v12.3 长蛋白/深负电增强后尤其明显，线性校准假设（slope·target+intercept）在弯曲段失效（curvature RMSE 全升）
2. **蛋白间响应异质性大**：per slope 0.97–2.01，单一 global 线无法代表所有蛋白（解释 per/global 口径反转：1BJ4 per 5/5 但 global 0/5；1CDG 反）
3. **trainish(训练域) vs valid(未见) 混拟合 global**：两者响应增益不同（训练域"见过"更理想），混在一起拟合的 global 对真未见蛋白有偏
4. 深负电区诊断点少 + 响应不稳定

**新方法（更新校准表）**：
- A. **小样本现场标定**（进行中，v12.2 用 n_per=10 采 50 条 → 74%）——最实际，绕开 global 平均
- B. **big-global 纯训练域表**（v12.2 noleak 方案：92 训练域 slope 1.459）——global 回退用训练域而非混 valid
- C. **分段/非线性校准**：诊断点足够（每蛋白十几 target），可对弯曲段分段线性或二次拟合
- D. 迭代自适应反推（先采测再调 target）
