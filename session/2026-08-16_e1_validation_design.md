## 三、实验设计：为什么采用混合设计

两种设计回答**不同的问题**，必须分层分工，不能只做一个：

| | 方案 A：同一 PDB 改条件 | 方案 B：各 PDB 用各自条件 |
|------|------|------|
| 回答的问题 | **机制/因果**：pH 引导是否真的驱动序列？ | **应用/泛化**：多样蛋白上系统是否可靠？ |
| 优势 | 变量严格受控，归因清晰 | 接近真实应用，检验泛化 |
| 弱点 | 单骨架结论难外推 | 条件不统一，跨蛋白比较有变量混淆 |

**只做其一都不够**：缺 A 效果无法归因（凑巧还是机制）；缺 B 只证明了一个蛋白。
**混合设计**（每个 PDB 内）：
```
① 基线组（生理/中性 pH，target=自然净电荷）5 条
   → 回折 TM-score vs 原结构 + pLDDT         ← 回答 B（泛化 + 结构保持）
② 条件组（pH 4 / 7.4 / 9 × target −5 / 0 / +5）各 3–5 条
   → 电荷偏差 + %sol + Tm 随条件的梯度        ← 回答 A（机制）
```
规模：4 PDB × (基线 5 + 条件 9×3) × 2 模型 ≈ 230+ 条。采样 GPU 快（分钟级），打分可后台批处理（ESMFold 1–2h / Protein-Sol 几分钟 / TemBERTure CPU ~40min）。

## 四、评价体系升级：TM-score 自洽性为主，pLDDT 为辅

- **pLDDT 是模型的自我置信度**（「我猜我折叠得不错」），高 ≠ 结构真正确，有被模型先验欺骗的风险——只能作辅助。
- **更强的证据是自洽性检验**：生成序列用 ESMFold 回折 → 存下结构 → 与原 PDB 骨架算 **TM-score / RMSD**（客观结构保持度）。这是逆折叠领域的标准评价（ProteinMPNN / ESM-IF 论文同法）。
- **成本几乎不增加**：TM-score 与 pLDDT 是同一趟 ESMFold（只多一步存结构 + 算 TM）。
- 实现：ESMFold 存 `.pdb` → us-align（Zhang Lab，`conda install -c conda-forge usalign`）算 TM-score。
- **结论**：扩展报告的主证据用「回折 TM-score vs 原结构」，pLDDT 作为辅助置信度展示。

---

## 五、位点固定（fixed residues）对照臂

- **可行性**：ProteinMPNN/LigandMPNN 原生支持固定残基（interface design 即「给定部分序列重建其余」），MoMPNN 权重同理。但 `run_guided.py` **尚无 `--fixed_residues` 参数，需新增**（featurize 时把固定位点 label 传入；bias 只加在非固定位点）。
- **效果权衡**：固定位点越多，可调节的电荷空间越小 → 净电荷 target 越难命中。直觉：目标电荷 − 固定区段电荷 = 剩余可变残基必须扛住的量。
- **可达性预检**：电荷可加和 → 用 `pka.py` 先算「固定后剩余位点的电荷可调区间」，预估 target 是否可达。可做成脚本内预检。
- **科学意义**：固定位点 = **有功能约束的再设计**（保留活性位点/结合面/二硫键 Cys），贴近真实蛋白工程。作为**对照臂**：先证无约束下条件控制有效（主线），再证有约束时仍有效（加分项）。

## 六、阈值防过拟合原则

1. **阈值来源用先验，不在当前蛋白上「调」**：
   - pLDDT>80 = AlphaFold 官方「可置信」分界（文献先验）
   - |电荷偏差|≤0.3 = 整数电荷目标的半命中容差（先验，不改）
   - %sol ≥ native = 以**同蛋白自己的 native** 为基准（相对值，天然不依赖绝对尺度）
2. **留一蛋白检查（leave-one-protein-out）**：阈值在 3 个蛋白上设定，在第 4 个上报告，4 次轮流；若结论翻转 → 样本/阈值不稳的信号。
3. **报告原始分布**：不只报通过率（均值相同但方差更小也是优势）；写明阈值来源 + 未做阈值搜索的声明。

## 七、Phase 2 训练数据：CATH 4.2 S40（ESM-IF 划分）

**推荐数据源**（直接支撑 Stage E2 自微调）：

- **CATH 4.2 S40 划分**：ESM-IF（Hsu et al. 2022，inverse folding）使用的划分，按 30% 序列同一性**同源剪枝**，**train/val/test 明确分离**（约 12k / 1.5k / 1.5k 结构域）。
- **为什么好**：① 本身是逆折叠任务，与我们同源；② **同源分离**天然防泄漏（test 不含与 train 序列同一性>30% 的结构），比随机划分科学；③ 自带序列/结构/二级结构/溶剂可及性（sasa）标签。
- **获取**：ESM-IF 官方仓库（`hsu1023/interface`）划分生成方式，或 CATH 官网 S40 列表。
- **关键分工**：数据集解决「结构 + 序列 + 同源划分」；**条件标签（pH / target_charge / 带电类型）用自有模块从结构现算**（`pka.py` + `differentiable_charge.py`），无需手工整理。
