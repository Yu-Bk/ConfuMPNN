## 一、数据侧结论（独立于 Claude 报告，来自 stats JSON 复算）

1. **v10-MoMPNN 崩在负目标域，形如"生成 ≈ 2×目标 + 负偏置"**：
   - 每蛋白拟合 生成=a·target+b：a∈[0.9,2.4]（1A65 2.09、1AXW 2.11、1BJ4 2.37），b 十蛋白全负（−2.4~−5.7）；
   - 分桶：neg 2..8 比值 2.31/命中 1/12；neg≤−8 比值 1.89/命中 0/28；pos 2..8 3/4；near0 混合；
   - 折叠全正常（TM 中位 ~0.85 甚至略升）。
2. **v10-Ligand 未崩**：native 4/10 vs v9 7/10、p2 8/10（改善）、n8 持平；GRAVY/recovery≈v9。
3. **判别**：两模型同用 A+B+C 而结果迥异 → 主因不是组件，是 **MoMPNN 训练 target 值域覆盖不足**（CATH native 多在 [−15,+15]；验证靶区 −19~−35 是外推）。
4. 与 Claude 报告的两处分歧：
   - 报告称"MoMPNN 唯一改动 decouple"↔ 管线脚本 MoMPNN 也带 B/C → 需训练日志定论（日志未 push）；
   - 报告称"decouple 无 native 锚点" ↔ 代码实为 target = native + Uniform(±12)（相对解耦）。
5. 已排除：归一化错配（checkpoint 自带 μ/σ）、欠拟合。
