# 第十八轮实施计划：通用模型（补高正电数据 + 逆密度加权）

> 日期：2026-08-17
> 目标：让模型对**任意电荷目标**（含高正电）都能命中，成为通用模型——根治 1BC8/2LZM 正电过冲。
> 决策（用户已确认）：**补数据 + 逆密度加权**；**先看本计划再执行**。

---

## 〇、诊断结论（数据 + 文献支撑）

| 发现 | 证据 |
|------|------|
| **训练数据偏负** | pH7 下 native 电荷 >+10 仅 **1.3%**（21/1608 条）、>+5 仅 7.2%、mean −2.5 |
| **高正电 target 在分布外** | 2LZM(+7.8)/1BC8(+8.9) 的 target +11/+12 在训练尾部之外 → 外推过冲 |
| **文献无直接解法** | `literature/` 四篇论文（P1-P4）都是"结构可设计性"对齐，无电荷分布外推方法 |
| **网络有标准解法** | 不均衡回归：**标签密度逆加权**（[US11720818B2](https://patents.google.com/patent/US11720818B2/en)）、**cost-sensitive learning**、**数据过采样**（[arXiv 2506.01486](https://ar5iv.labs.arxiv.org/html/2506.01486#1)）——专治"外推目标过冲" |
| **数据可补（零下载）** | `data/cath/S40/dompdb/` 已有**全部 34,653 域**（无后缀原始文件），只用了 999；**分层采样可行**：−20~+20 分 8 箱全有数据（实测 [−15,−10) 2,333、[+5,+10) 1,801、[+10,+15) 308、[+15,+20) 76）|

## 一、阶段 0：分层平衡重采样（替换随机抽样，非补数据）

> ⚠️ **修正（2026-08-17 用户反馈）**：原方案"999 随机 + 补 2500 正电"会让正电占训练集 71%，
> 从偏负倒向偏正——**采样不合理的另一极端**。正确做法是**分层平衡采样**：按 native 电荷分箱
> 每箱等量抽取，训练集电荷分布均匀覆盖全范围，正电域数量与负电相当。

**实测分布**（`tests/domain_charge_dist.py`，34,612 有效域，电荷@7.4）：

| 区间 | 域数 | | 区间 | 域数 |
|------|------|---|------|------|
| [−20,−15) | 634 | | [+0,+5) | 8,254 |
| [−15,−10) | 2,333 | | [+5,+10) | 1,801 |
| [−10,−5) | 7,379 | | [+10,+15) | 308 |
| [−5,+0) | 13,504 | | [+15,+20) | 76 |

**做法**：
1. 按 native 电荷@7.4 分 **8 箱**（−20~+20，5 单位一箱），每箱**等量抽取 ~100 域**（[+15,+20) 只有 76，全取）。
2. 得 **~776 域平衡集**，电荷分布均匀覆盖 −20~+20（正电域 ~475 与负电 ~300 数量级相当，不再稀疏也不再超量）。
3. 为选中的域在 `dompdb_pdb/` 建 `.pdb` 符号链接（train_finetune 依赖 .pdb 后缀）。**彻底替换**当前 999 随机抽样域。

**产出**：平衡训练域清单 + 符号链接（新训练集 ~776 域）。

## 二、阶段 1：标签重建（~5min 脚本 + 重算 μ/σ）

**做法**：改造 `build_labels.py` → `build_labels_v2.py`，支持：
- `--stratify` 分层抽样：按 native 电荷分箱（`--n_bins 8 --per_bin 100`）每箱等量抽取，替换原随机抽样
- `--n_pH 8` 不变：每域 8 个 pH（uniform[4,10]），charge = native 在该 pH 净电荷
- 输出 `data/cath/labels_balanced.npz`（不覆盖原 labels.npz）

**⚠️ μ/σ 重算**：加入高正电域后训练集电荷均值会上移（偏正），必须重算 condition_defaults.yaml 的 normalization μ/σ（build_labels 现有逻辑会写），否则编码器输入标准化错位。

**产出**：`labels_balanced.npz`（~3500 域 × 8 pH ≈ 28,000 样本）+ 更新 μ/σ。

## 三、阶段 2：训练改动（逆密度加权，~30min 编码）

**文献原理**：不均衡回归中，损失函数被多数样本主导，导致少数样本（高正电 target）拟合差 → 外推过冲。解法 = 对损失按**目标密度逆加权**：`weight(target) = k / (density(target) + ε)`，稀有 target 权重更大。

> **配合分层平衡采样**：分层后训练分布已均匀，但极端箱（[±15,±20)）域仍远少于中间箱（[-5,+5) 有 2 万多 vs [+15,+20) 76），
> 且扰动会把 target 推到分箱边缘——逆密度加权对极端 target 仍有额外加权意义，两者互补。

**实现**（`train_finetune.py`）：
1. 预计算 target 密度表：从 `labels_balanced.npz` 的 charge_label + 训练扰动分布（±Uniform[1,8]）估算训练时 target 的分布密度（直方图分箱 0.5 宽度，或 KDE），存为 numpy 数组 `density_table`（覆盖 −40~+60）。
2. charge loss 循环里：`weight_i = k / (density_table[bucket(target_i)] + ε)`，`cd[i] *= weight_i`。
3. 参数：`--loss_reweight`（默认 0=关，1=开）、`--reweight_k`（默认 1.0）、`--reweight_eps`（默认 1e-3）、`--reweight_cap`（weight 上限，默认 5.0，防过校正）。

**保护机制**（文献警示：naive 加权牺牲频繁样本）：
- weight 上限 cap 防高正电样本权重过大压坏负电命中
- 复验监控负电 target 命中不回退（若回退，调低 k 或关闭）

**产出**：可开关的逆密度加权训练代码。

## 四、阶段 3：重训 + 复验（~25min 训练 + ~40min 打分）

**重训**：`train_finetune.py` 用 `labels_balanced.npz` + `--loss_reweight 1`，30 epochs（域数 ~3500，训练时间约 25-30min）。

**复验**（更新 `phase3_v2_validation.py`）：
| 臂 | 设计 | 判 |
|----|------|----|
| t1_cond / t1_base | 目标 1 形态（不变）| H2/S4 |
| t2_pos_mild | target = round(native)+3 | H2（温和正电）|
| **t2_pos_extreme** | target = round(native)+8 | H2（**极端正电**，本轮重点验证高正电外推）|
| t2_neg | target = round(native)−5 | H2（监控负电命中**不回退**）|
| t2_ph | 均值占位 | H1（确认占位符修复保持）|

**新增泛化验证（通用模型核心）**：从筛选出的高正电域中挑 **1-2 个未训练过的新 PDB**（native>+5，且不在训练域），用 `run_guided.py` 跑 target = 天然电荷 ± 5，验证：
- 新正电蛋白上正电 target 命中（不再过冲）
- 折叠回骨架（H1）
- **这才是"通用模型"的真正证据**——模型没见过的蛋白也能正确控制电荷。

## 五、风险与保护

| 风险 | 保护 |
|------|------|
| 逆密度加权过校正（文献警示）| weight 上限 cap；复验监控负电命中不回退；必要时调 k 或关闭 |
| 训练时间增加（域数 ~3.5×）| 可接受（~25min）；若太久可减高正电域数 |
| 高正电域结构质量 | CATH S40 已非冗余、结构可信；筛选时排除 <20 残基域（parse_domain 已有）|
| μ/σ 变化影响 | 重算并写入 config；编码器重训使用新 μ/σ |
| 复验 PDB 泄漏 | 新增验证 PDB 严格排除在训练域之外（检查 domain_ids）|

## 六、判定标准（v2，不变）

- **H2 核心改进目标**：t2_pos_extreme 从 dev 4.6~8.7 → **≤2.0**（1BC8/2LZM 命中）
- **不回退**：t2_neg 保持 dev≤2.0（4/4）；t2_ph 保持折叠（H1）
- **通用性**：新增正电验证 PDB 上 H2 命中 + H1 折叠
- 其余：H3/S4/S1*/S2 按 v2 报告
