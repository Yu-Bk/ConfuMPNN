# ConfuMPNN 条件序列设计 —— 判断标准 v2

> 日期：2026-08-17
> 用途：定义"条件注入生成"（pH/电荷条件 → 序列设计）的 **PASS/FAIL 判据**。
> **v1 → v2 主要修订**：
> 1. **S1 从硬判据降级为软监控**——v1 要求"A 场景 identity≥0.7"，但用户两个真实目标都要**全新序列**，
>    序列重写是期望行为，"要求保持"与之矛盾（见 §1.5）。
> 2. **对齐两个真实目标**：① 天然骨架（RF3 relax 微调后）→ 全新序列 + 理化性质≈天然；
>    ② 人工设计骨架（靶点口袋）→ 全新序列 + 简单理化预期（部分条件用占位符不控制）。
> 3. 新增**占位符语义**与**位点固定行为**判据。
> 4. identity 降级为"相似性软区间 + 防坍塌监控"（文献支撑：P2 ResiDPO 的 RCL / P3 坍塌教训）。

## 一、哲学原则

本项目是**基于结构的蛋白序列设计（inverse folding）**：**骨架固定，序列可重写**。

1. **序列重写是设计行为，不是破坏**。给定骨架设计新序列，序列改变是本分。
2. **"改了 pI 还要求序列与原蛋白相似"是自相矛盾**。pI 由序列决定——要改 pI 就必须改序列。
3. 唯一合理的参照：存在**骨架相似但 pI 不同**的天然蛋白对时，"改 pI" = 从天然状态 A 设计到天然状态 B。
4. 因此可溶性 / 热稳定等**新序列固有属性**是**设计权衡**，不是失控——除非破坏源自"折叠不回骨架"。
5. **两个真实目标都要"全新序列"**（目标 1 只求理化性质≈天然，目标 2 求符合简单预期）→ 序列与天然
   相似度**不是交付物**。它只作为"结构/理化稳定性"的软代理指标（§3 S1\*）。

## 二、硬约束（任一不满足 → FAIL）

| # | 判据 | 量化阈值 | 依据 |
|---|------|---------|------|
| H1 | **结构自洽性**：条件臂序列经 ESMFold 回折，能折叠回给定骨架 | 回折 TM-score **中位数 ≥ 0.70**（TM>0.7=相同拓扑，Zhang & Skolnick 2004）；折叠失败率（TM<0.5）**≤ 10%**（n=20 内 ≤2 条） | 逆折叠的立身之本：设计出的序列必须能折回原骨架（整体相似即可，不要求逐残基一致） |
| H2 | **电荷目标命中**：条件臂实际净电荷达到 target | \|平均实际电荷 − target\| ≤ 2.0 | 条件设计的核心交付物；目标 2 从零设 pI 时尤其关键 |
| H3 | **电荷聚集合法性**：不违反生物物理电荷规律 | 条件臂序列在结构过滤器规则下**违规率 ≤ 基线违规率 + 5 个百分点** | 任何设计不得产生物理上不可能的电荷布局 |

> **H1 是核心**。TM-score 中位数达标 = "能折叠回骨架"，离群点（TM<0.7）单独计数 = 捕获"个别垃圾序列"。

## 三、可控性判据（软，报告但不单独判 FAIL）

| # | 判据 | 量化阈值 | 依据 |
|---|------|---------|------|
| **S1\* 相似性软区间** | 序列与天然（/无条件基线）的相似度 | **identity 落 0.4–0.7 为健康**；配合**防坍塌监控**（生成序列两两 identity < 0.8、每位置熵不骤降） | 一定相似度（0.4–0.7）保证结构/理化稳定、更容易成功；过低（<0.4）提示序列过激进，过高（>0.7）提示可能坍塌。**非硬 FAIL**。文献：P2 ResiDPO RCL（选择性保序列）、P3 Weighted-score DPO 坍塌教训 |
| **S2 可开发性权衡** | pLDDT / %sol / Tm 绝对值 | 报告，不单独判 FAIL | 电荷目标与可溶/热稳存在本质张力（如低 pH 高正电天然可溶差） |
| **S3 占位符语义** | 未控制维度（flag=0）不影响其他控制条件生效 | 对比"全控制"与"部分占位"两臂的已控制指标，差异应在噪声内 | 目标 2 明确要求"部分条件不控制用占位符" |
| **S4 位点固定行为** | 固定位点序列=指定值；未固定位点正常设计 | 固定位置 100% 保持；H2 命中不受位点固定破坏 | 目标 1 明确要求"固定保守位点后设计其余" |

## 六、训练修正方向（第十五轮，对齐目标 2 + 治 H2）

1. **治 H2（2LZM 过冲 / 1CRN 欠调）**：扰动幅度 `--perturb_scale 4 → 8`——让模型见过「补 6–8 单位电荷」需求
   （2LZM A 需补 +6.32、B 需压 −8.41，均超原分布；1CRN 欠调同理，开关太少够不着）。
2. **占位符语义（S3）**：训练注入 `--placeholder_prob 0.15` 占位符样本（两种语义各半），
   让「电荷不控制」成为合法语义，推理占位不 OOD。
3. **identity 软约束（S1\*）**：`λ_keep` 维持 0.5 不再加压；seq-keep 保持护结构；复验加防坍塌监控。
4. **可选（借鉴 P2 RCL）**：选择性 seq-keep——只在无条件 top1 概率 > γ 的高置信位点约束。

## 七、验证流程（对齐两目标）

```
目标 1 形态（天然骨架）：A 场景 target=天然电荷 + --fixed_residues 固定保守位点
   → H1 折叠 / H2 pI 命中 / S2 理化性质 / S4 位点固定 / S1* 相似性软区间
目标 2 形态（模拟人工骨架）：target 从零设 pI（不取天然）+ 部分条件占位符
   → H1 折叠 / H2 命中 / pLDDT 稳定 / S3 占位符语义
防坍塌监控：生成序列两两 identity + 每位置熵（写入复验统计）
打分管线：ESMFold 回折 → us-align TM → Protein-Sol → TemBERTure（HF_HUB_OFFLINE=1）
判定：H1/H2/H3 硬约束 PASS/FAIL；S1*/S2/S3/S4 软监控报告
```
