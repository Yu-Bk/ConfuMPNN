**机制史提炼（蛋白线每轮修什么）**：
1. **v7 时代**：只有"净电荷"监督 → 模型发现删捷径（成对删 K+D 净电荷不动、只降带电总数）→ P1。
2. **v10 B(L_add) 为什么有害**：① 代码 bug——v10_losses AA 索引偏 1，实际监督的是 E+F/M+S 而非 D/E+K/R；② 语义叠加——L_add 要求"表面再加 Δ 个 D/E"，与模型本来的"删 K/R 凑负电"同向双算 → 净效果≈2×Δ，负向超线性过冲；③ 只盯"加 D/E"，对删 K/R 完全不设防。v11a(B-OFF) 证明去 B 净收益。
3. **v12 三件套为什么治删**：`surface_composition_loss` 对 **D/E 与 K/R 分别设下限**（堵成对删：删哪一边都触发 relu）；`surface_gravy_loss` 把"删带电换疏水"导致的表面 GRAVY 上升也罚掉（带电总数的代理约束）；`λ_target surface_charge_target_loss` 把"净电荷=target"的实现路径**钉在表面添加**（表面净电荷=target−核心 native，核心锁死）。
4. **v12.2 上界锚（λ_target）补 v12 的洞**：v12 只有下限 → 模型为达 target 只能"加"，且加多不罚 → 过度添加 1.5-2×。λ_target 把表面净电荷设为目标值，既是下限也是上限 → "加多少"一步到位（治正向弱 + 防滥加）。
5. **但 surface floor 只覆盖 frac_sasa≥0.25 的"表面"** → 埋藏/低 SASA 带电残基仍可被删（蛋白模式也有，见 §三 2FEO core 0.25）。

## 四、机制分析：为何蛋白模式较轻、配体模式即便 A1-global 仍删

### 4.1 共同的底层捷径
净电荷监督（可微 HH 电荷 loss）只约束"总净电荷=target"，不约束"带电残基总数"。于是模型学会**成对删**：删一个 K(+1) 就删一个 D(−1)，净电荷分毫不动，带电残基总数下降（收敛低电荷密度）。天然蛋白可同时含大量正负电（1BJ4 native 52D/53R），"净电荷小≠带电残基少"——删空一边会丢电荷斑块。**阻止捷径的唯一训练侧手段 = 按分区对 D/E、K/R 分别设计数下限**（v12 surface floor / v13-14 pocket count）+ GRAVY + λ_target。

### 4.2 蛋白模式（MoMPNN）为何较轻 —— 四层
1. **覆盖面**：CATH 单域训练几乎无配体遮蔽 → 带电残基绝大多数 frac_sasa≥0.25 → `surface_composition_loss` 覆盖全链绝大多数电荷。删到 floor 就被拦（v12.2 floor=0.5 → 表面保留基本 ≥0.5-0.6）。
2. **先验**：MoMPNN 无条件先验接近"保留 native 组成"；微调才带出删减，且删减是全局均匀的，没有某个"低监督、高电荷"热点区可集中删。
3. **埋藏带电"用武之地"少**：球状蛋白核心埋藏带电残基少（表 1 里 1BJ4 全链 105 带电只有 22 个在 core、1AS2 84 中 13 个 core），且多为结构必需（盐桥/H 键），删了伤折叠 → CE/SeqKeep/结构惩罚兜底。
4. **λ_target 把电荷变化引到表面添加**：核心净电荷锁 native，表面净电荷=target−核心 → 调电荷主要靠表面加，而不是全局删。

**蛋白模式为什么仍删 0.49-0.77（不是根治）**：floor 0.5 本身容差宽松 + 埋藏/低 SASA 残基（core、深沟）仍在 surface 监督之外 → 这些可自由删（2FEO protein core 0.25、1AZM surface 0.50）。所以蛋白模式是"较轻、较均匀、表面有下限"，不是健康。

### 4.3 配体模式为何即便 A1-global 仍删 —— 四层
1. **frac_sasa 盲区**：深口袋（结合面）被配体/核酸遮蔽，60-75% 口袋残基 frac_sasa<0.25 → 划"核心"，**在 v12 的 surface floor/GRAVY/λ_target 监督之外**（监督逃逸）。v12.2-ligand 实测 2FEO 深部口袋带电 native 10→1.5（0.15×）。
2. **配体疏水先验 + atom context**：LigandMPNN 训练分布里口袋偏疏水；模型输入有配体原子上下文（atom_context=25）→ "知道"口袋在哪，且先验"喜欢"在口袋删带电。**原始 LigandMPNN 已删 10-22% 口袋电荷**（2FEO 13→10.2），只是无全局删减；v12 微调把它放大 2-3×（→0.23-0.54）并新增全局删减（→0.53-0.65）。
3. **电荷"用武之地"集中在埋藏结合界面**：核酸结合蛋白的结合界面携带大量带电残基（表：21KL_A pocket 30、5O60_E pocket 27、3MXB_A pocket 21、1AS2/2FEO/5CQH pocket 11-14 个 native CHG）。这些残基低 SASA → 不受表面 GRAVY 罚；成对删 → 不受净电荷罚；删除位置靠配体 → 符合疏水先验 → CE 支持。**"在配体界面上删带电"是最省力、最不破坏"模型眼中的结构合理性"的路径**。v14 删除定位判别支持：越埋藏越重删（AUC 0.83）、越靠配体越重删（AUC 0.65）、重删位点绝大多数 = "分布式"（616 个 native 带电位点里 583 个保留≤0.6）。
4. **A1-global 覆盖了 surface∪pocket 仍不够**（v14 0.43-0.69）：
   - **全局归一化稀释口袋**：v14 `pocket_count_loss` normalize=True，对**整个 surface∪pocket 区域**做 floor/ceil → pocket 的深删（0.26-0.49）被 surface 的浅删（0.47-0.83）"平均掉"，区域级 floor(0.8) 在多数蛋白上仍被违反（surface 保留 0.47-0.83 大量 <0.8），说明该 soft loss 权重（λ_pocket=0.3）**压不过** CE + charge + 先验。
   - **fixbinding 反证**：把结合口袋 100% 钉成 native 后，surface/core 删除几乎不动（0.60→0.61 / 0.39→0.37）→ 删减主体是模型**全局默认的"半电荷密度"分布**，不是口袋逃逸独有；覆盖再大也只是缩小逃逸区，不改变默认分布。同时 H2 崩到 36% → 删减是模型达成电荷 target 的主要杠杆，拿走它就缺替代机制。
   - **largen 证据**：n=200 下"电荷达标+不删(≥0.7×)+无聚集"三达标序列存在但仅 5.2%（删除通过率 17.5% ≪ 电荷 32.1%）；40% 的臂 n=200 仍为零 → 模型默认分布系统性偏删除，不是稀有事件可救。

### 4.4 "电荷目标尺度 / 序列长度"差异不是主因
- native 臂 target = 蛋白自身 native 电荷（无扰动），配体 v14 仍删 0.43-0.69 → 删除不依赖极端 target，是默认习惯。
- 配体训练集长度覆盖其实好于蛋白（配体 L>400 占 19%，CATH 仅 2%），但配体删得更重 → 长度不是解释。
- 唯一"长度×深负"叠加的 1A65 上，两模式反而是**过度添加**（蛋白 1.23 / 配体 1.32），说明深负长尾的响应机制与"删减捷径"是两回事。

## 五、结论

1. **前提修正**：蛋白 v12.2 是"较轻、均匀、表面有 floor 下限"的删减（native 臂 8/10 = 0.49-0.77×，1C6O≈1.0、1A65 是 1.23× 过度添加）；不是"健康/不删"。配体 v14 是"全部蛋白、定向口袋且更深"的删减（0.43-0.69×）。
2. **同一捷径、两套命运**：删减捷径（成对删 D+K 保净电荷）两模式共有；蛋白模式被"surface floor 覆盖绝大多数电荷 + 无配体疏水先验 + 埋藏带电池小"挡住；配体模式被"深口袋 frac_sasa 盲区 × 配体疏水先验 × atom-context 定向 × 结合面=带电富矿 × 微调放大"打通。
3. **A1-global 未根治的原因**：覆盖是必要非充分。计数 floor 是弱 soft loss（λ0.3，global 归一化稀释口袋局部），敌不过 LigandMPNN 疏水先验 + CE 的持续强化；fixbinding 证明删除是全局默认分布而非单一逃逸口。
4. **论文/工程口径建议**（与项目 memory 决策 D 一致）：蛋白 v12.2 可作主交付，但 native 臂组成 0.5-0.8× 需如实报告（surface 可控、总体轻删）；配体模式删减为跨版本未决已知局限，fix/largen 只能缓解不根治；真正治本需更强的"带电总数双向硬约束"（如提高 λ、分区域独立 floor、或非归一化的绝对计数约束）。
