## 二、校准表四表对比（用户重点）

**四个校准表**（注意：**v12.2 用的是 n20 诊断**，v12.2 尚未跑 n50）：

**三表区别 + 实际提升数据**：

**① n20 → n50（v12.1 时代，`charge_calibration_v12_1_n50`）**
- **区别**：n50 是**同一 17 蛋白诊断用 n=50 采样重拟合**（n20→n50 每 target 采样翻 2.5 倍），**global 几乎不变**（1.748→1.749），改的是 **per_protein 参数**——高方差蛋白（2FEO/1AXW/1AS2/1A65）的 n20 拟合噪声大
- **实际提升**：
  - 2FEO intercept 大幅修正（−7.26→−5.61）→ seed2000 dev **3.75→2.03**、seed3000 **→1.40**（seed 敏感性消除）
  - 好蛋白参数稳定（slope 变化仅 0.3-3.1%），1AXW 双峰不变（校准非其瓶颈）
  - 泛化 H2 28→**29/50**（系统性差蛋白修复，总达标率基本持平）
- **教训**：n50 治"高方差蛋白的校准噪声"，不治模型本身的响应/分布问题

**② v12.1 → v12.2（同为 n20）——提升来自模型（λ_target），不是校准**
- **区别**：v12.2 校准表是 v12.2 checkpoint 的诊断（n20）——**global 1.748→1.579、intercept −6.342→−3.139**（λ_target 训练侧让响应增益变小、偏移变小）
- **实际提升**：校准后 slope 1.04→**1.00**；泛化 H2 58%→**72%（+14pp）**——主要是 v12.2 治正向弱（p2/p8 35%→60%）+ 响应更准，**不是校准表改动（都是 n20）**

**③ v12.2 n20 per-protein vs big92 global（无泄露口径）**
- **区别**：per-protein = 每个评估蛋白自己的响应直线（**有响应信息，已标定**）；big92 global = 训练域平均直线（**无泄露**，陌生蛋白）
- **实际差距**：**72% vs 44%（差 28pp）**——这就是"标定 vs 不标定"的真实代价
- **关键发现**：校准表扩到 92 域（460 点）**不改善陌生蛋白**（big92 44% ≈ hold-out 40.6%）——响应增益蛋白特异，训练域平均救不了增益偏离的蛋白

**④ 小样本现场标定（表外蛋白的正确用法）——实证成功**
- **区别**：不建 global 表，对目标蛋白现场采 5 target（native±[8,4,0,4,8]）× n10 = 50 条，拟合该蛋白自己的 slope/intercept（临时 per-protein）
- **实际提升**：泛化 10 蛋白 H2 **37/50 = 74%**，**高于** per-protein 诊断表（72%）、远高于 global 兜底（44%）
- **1BJ4/2FEO 从 0/5 救回 5/5**：这两个高方差蛋白的 n20 诊断拟合噪声大，现场标定（slope 1BJ4=3.007、2FEO=1.391）反而拟合准 → **之前"高方差蛋白需 n50"的教训被小样本标定取代**
- **1A65 仍 0/5**（长蛋白欠冲，模型侧问题非校准）——小样本标定救不了

## 三、结论 + 使用指南

1. **v12.2 模型本身强**：per-protein 72%、小样本标定 74%、无过拟合、slope 达标——**λ_target 是有效的训练侧改进**（治过度添加 + 正向弱）
2. **校准表选 n20 即可**（对 v12.2）：模型响应已较准（slope 1.579），n20 校准后 72%
3. **陌生蛋白必须小样本标定（已实证 74%）**：表内→per-protein（72%）；表外→现场采 50 条拟合自身 slope 即可到 74%（比 global 兜底 44% 高 30pp）；不标定 global→如实报 40-44%
4. **1BJ4/2FEO 用现场标定而非 n50**：小样本标定已直接修复这两个高方差蛋白（0/5→5/5），**无需再跑 v12.2 n50**

## 四、剩余短板

1. **1A65 长蛋白"响应弯曲"导致小样本标定失效**（per-protein 5/5，但小样本 0/5、big-global 0/5）：非随机噪声，是确定性偏差——1A65 响应曲线在极端负电区急剧弯曲（局部增益 0.7→2.7），小样本 5 点全落弯曲段 → 线性拟合失真 → target_eff 推浅 → dev 3-4。**插值验证吻合**。启示：小样本标定对响应近线性的蛋白有效，对响应明显弯曲的蛋白需覆盖含正电端的更广 target
2. **1AXW 双峰蛋白小样本下 1/5**：响应分布本身双峰，标定无法完全拟合
3. **1BJ4 组成 0.59× 偏低**：λ_target 锚 target≈0 表面净电荷 → 带电残基偏少，正电化受限（已由泛化 p8 反映）
