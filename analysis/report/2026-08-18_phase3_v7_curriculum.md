## 4. 遇到的问题（诚实记录）

1. **极端正电"两极化"**：外部碱性数据 + 课程学习解决的是**本身碱性/大蛋白**（2LZM L=164、1CRN 特殊 crambin）的正电外推；但对**超高正电 target + 小/中性蛋白**仍过冲：
   - 1BC8 极端 +22.45 vs +17（dev 5.45，比 v6 还差）
   - 1UBQ 极端 +5.46 vs +8（dev 2.54，v6 1.79）
   - 1b24A01 极端 +20.58 vs +16（dev 4.58，改善但仍不过）
2. **1CRN 折叠大幅退化（4/6→1/6）**：5 臂失败率 0.15-0.20（TM<0.5 比例超标）。唯一 L=46 极端小蛋白，native ESMFold pLDDT 48.7 本身边缘。
3. **1b24A01 H2 退化（3/5→2/5）**：t1_cond（target=+8=native）也过冲到 +10.21（dev 2.21），无条件生成偏正电。
4. **H3 负电臂违规新增 1UBQ t2_neg**。

## 5. 根因分析

### 5.1 极端正电过冲未根治的本质：条件组合的分布外，不是样本量

外部碱性 678 域全部是 **native 电荷 ≥+5 的碱性骨架**，其训练标签是"该骨架自己的高正电 target"。模型学到的是"**碱性骨架 → 正电序列**"的映射。

而 1BC8（L=93）+17、1b24A01（L=95）+16、1UBQ（L=76 中性）+8 要求的是"**非碱性小骨架 → 极高正电 target**"的组合——**训练数据中不存在这个组合**（所有碱性样本都是碱性骨架，所有中性样本的 target 都≈自身 native）。模型对这个组合只能线性外推条件向量 → 过冲。

证据：2LZM（本身碱性 L=164）极端 target +16 达标（1.07）——因为它在"碱性骨架"分布内；1CRN（crambin 天然富 K/R）+7 达标——骨架本身就能容纳。**不是"多给碱性样本"能解决的，是"碱性 target 与骨架类型解耦"没做。**

### 5.2 1CRN 折叠退化：小蛋白 + 课程后期极端扰动的耦合

1CRN 是唯一 L=46 的极端小蛋白，ESMFold 对其折叠本就边缘（native pLDDT 48.7）。v7 各臂失败率 0.15-0.20（连 t1_base 无条件也 0.20）→ 不是条件臂单独问题，是**整体生成质量下降**。

可能因素：① 课程学习后期 perturb 到 8.0，模型被训练"更顺从电荷条件"，削弱结构约束（seq_keep 只约束自洽样本）；② 外部碱性域加入后训练分布更偏长链/正电，小蛋白骨架在批内被稀释。两个因素在小蛋白上叠加放大。

### 5.3 1b24A01 持续困难

native +8.0 但无条件（t1_base）TM 中位仅 0.749、生成 pLDDT 63-69 偏低——这个域外蛋白本身与训练骨架同源性弱，v4 起就折叠偏弱。v7 的 t1_cond 过冲 2.21 说明连"target=native"都响应过度，是"电荷目标与骨架本征电荷"张力的典型。

## 6. 结论

v7 相对 v6：**H2 +1（20/25）、H1 −3（22/30）、目标 1 形态 −1（4/5）**。课程学习的净收益集中在**温和扰动 + 本身碱性骨架的极端正电**（2LZM 根治、温和全达标），但**付出 1CRN 折叠退化 + 1b24A01 t1_cond 退化的代价**。

用户担心的"噪声过多影响折叠"在数据上有印证：课程学习后期极端扰动（scale 8.0）+ 外部碱性域稀释小蛋白分布，叠加在小蛋白（1CRN）上导致折叠保真下降。**极端正电过冲的根因从"样本量不足"修正为"碱性 target 与骨架类型未解耦"**——外部数据补的是"碱性骨架"这一侧，缺的是"任意骨架上给任意正电 target"这一侧。

## 8. 下一步建议（v8 候选）

1. **治极端正电分布外（核心）**：把 perturb 与骨架 native 解耦——训练时**对任意骨架施加与自身 native 无关的随机正/负 target 扰动**（跨类扰动），让"中性骨架 + 高正电 target"成为训练分布内的组合。这是 v7 数据策略缺的一环，且成本低（只改 perturb 采样逻辑）。
2. **治 1CRN 折叠退化**：课程学习后期降低极端扰动占比（用户"不要让极端变主流"原则），或对自洽样本提高 seq_keep 权重。
3. **H3 负电臂**：结构过滤器对酸性聚集（t2_neg）规则偏严，需单独评估负电臂判据。
