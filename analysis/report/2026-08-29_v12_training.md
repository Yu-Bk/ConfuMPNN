# 分析报告 — v12 训练侧监督实验：治删减成功、但过度添加（2026-08-29）

> **背景**：v11 四版消融全未达标 → 校准（v12 §7.1）解决响应过冲 → 但校准**不治删减捷径**（删 K/R 非加 D/E）。v12 §7.2 训练侧监督（组成双计数 + GRAVY）目标是根治 P1。
> **本文**：v12 训练（30ep）+ 闭环诊断 + D/E/K/R 组成对比，判定 v12 方向是否有效。
> **一句话结论**：**v12 成功堵死删减捷径（生成 D/K ≥ native），但参数过强导致过度添加（D/K 超 native 1.5~2×）→ 响应过冲（slope 1.85）需调参。**

---

## 1. v12 配置

v12 = v11a 配置（decouple 相对 ±12 + C 结构惩罚 boost1.5）+ 新增训练侧监督：
- `surface_composition_loss`：表面 D/E 和 K/R **双计数**都不许低于 native×frac_floor(0.8)
- `surface_gravy_loss`：表面 GRAVY ≤ native + margin(0.15)
- λ_v12=0.3；30ep MoMPNN；训练收敛正常（charge 2.87、keep 0.90，无 NaN）

## 2. 闭环诊断（响应曲线）

| 版本 | valid 区内 slope | trainish 区内 slope |
|------|:---:|:---:|
| v10 | 1.67 | 1.48 |
| **v11a**（最佳基线）| **1.41** | 1.49 |
| v11b | 1.50 | 1.34 |
| v11c | 1.57 | 1.35 |
| **v12** | **1.85 ± 0.58** | 1.92 ± 0.69 |

- **v12 slope 五版最差**（1.85）；native 自洽点也过冲（7pujA01 −12→−29.9、2uv8A05 −16→−71）
- slope 过冲可由校准修复（§7.1 已证明），但**过加可能伤折叠**（未测 v12 TM）

## 3. D/E/K/R 组成对比（P1 删减捷径判据）

5 蛋白 × 编码器（v11a/v12）× target（native/n−8）× n10，统计 D/E/K/R 总数：

| 蛋白 | native D/K | v11a native | v11a n−8 | v12 native | v12 n−8 |
|------|:---:|:---:|:---:|:---:|:---:|
| 1C6O | 34 | 31.9 | 39.0 | **64.5** | 69.7 |
| 1AG0 | 56 | 43.1 | 61.7 | **91.2** | 103.4 |
| 1BJ4 | 105 | **29.3**（删光）| 65.8 | **159.8** | 167.9 |
| 1A65 | 79 | 92.4 | 94.5 | **163.6** | 177.9 |
| 7pujA01 | 74 | 47.7 | 60.1 | **96.5** | 103.6 |

**发现**：
1. **v12 停止删减**：全部 5 蛋白 v12 的 D/K ≥ native（1BJ4 105→159.8、1A65 79→163.6）——P1 删减捷径被堵死。
2. **v11a 仍走删减**：1BJ4 105→29.3（删光 D/E）、1C6O 34→31.9（不增反删）。
3. **v12 过度添加**：D/K 超 native 1.5~2×——响应过冲（slope 1.85）的直接原因；K/R 也过度保留（负电荷化时 K 不减）。
4. 负电荷化（n−8）时 D/E 增加方向正确（1C6O 39→47、1AG0 58→71）。

## 4. 结论与修正方向

**v12 方向有效但参数过强**：
- 组成+GRAVY 监督**确实能堵死删减**（比 L_add 更本质：双计数 + 总量代理）。
- 但 `frac_floor=0.8` + `gravy_margin=0.15` 双下限太严 → 模型只能"加"，且 K/R 也被强行保留 → 过冲。

**v12.1 调参方向**（按敏感度）：
1. **frac_floor 0.8 → 0.5**（允许删 50%——删减捷径是"无差别删光"，允许温和删减仍能堵死"删光"）
2. **gravy_margin 0.15 → 0.4**（放宽疏水容忍）
3. 或 **只用 GRAVY**（总量约束）不用组成（定向约束）——GRAVY 已覆盖"总量防删"核心
4. λ_v12 0.3 → 0.2
5. 校准（§7.1）始终兜底 slope

**与校准的关系**：校准修 slope（响应增益），v12 修组成（防删减）——两者互补，v12.1 达标后可叠加校准交付。
