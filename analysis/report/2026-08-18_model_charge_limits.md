# ConfuMPNN 电荷控制能力：可靠工作范围与限制说明

> 日期：2026-08-18　用途：**使用指南**——明确本模型在电荷控制（pH/净电荷条件）上的可靠范围、警告范围与限制范围，保证用户在"绝大多数蛋白"上可放心使用。
> 数据来源：训练分布（`labels_balanced_v7.npz` 7,886 域）+ v5/v6/v7 三轮复验（5 PDB × 6 臂 × n=20，共 90 个电荷命中判据）。
> 判定标准：DESIGN_CRITERIA v2，H2 = |实际电荷 − target| ≤ 2.0。

---

## 一、结论先行：三区间

设 `target` 为输入电荷目标，`native` 为目标蛋白天然净电荷（pH 7.4 下）：

| 区间 | 电荷目标范围 | 命中率（v7） | 建议 |
|------|------------|-------------|------|
| ✅ **可靠区** | `native − 8 ≤ target ≤ native + 2` | **91–100%** | 放心使用 |
| ⚠️ **警告区** | `native + 3 ≤ target ≤ native + 5` | **83%** | 谨慎使用，检查结果 |
| 🔴 **危险区** | `target > native + 5`（极端正电） | **40%** | 避免；或先确认骨架能容纳高正电 |

**核心表述**：
- **绝大多数蛋白（电荷目标接近其天然值或偏负电）都在可靠区**——模型表现稳定。
- **唯一系统性失效场景：把小骨架蛋白改造成"远超其天然值的强正电"**。这是本模型明确的限制。

## 二、数据证据

### 2.1 训练数据的电荷覆盖范围（模型"见过"什么）

7,886 个训练域，pH 7.4 净电荷分布：

| 电荷区间 | 域数 | 占比 |
|---------|------|------|
| [−15, −10) | 539 | 6.8% |
| [−10, −5) | 1,657 | 21.0% |
| [−5, +5) | 2,688 | 34.1% |
| [+5, +10) | 2,089 | 26.5% |
| [+10, +15) | 478 | 6.1% |
| [+15, +20) | 135 | 1.7% |
| 其余（±20 外） | <1% | — |

→ **[−15, +15] 覆盖 92%，[−10, +10] 覆盖 81.6%**。天然蛋白的绝大多数落在模型见过的高密度区。

### 2.2 v7 复验命中率随"目标偏移"的变化（核心证据）

5 PDB × 6 臂 × n=20，按 `target − native` 分箱：

| 目标偏移 | 臂数 | 达标 | 命中率 | 失败案例 |
|---------|------|------|--------|---------|
| target ≤ native−7 | 3 | 3 | **100%** | 无 |
| native−6 ~ native−3 | 5 | 5 | **100%** | 无 |
| native−2 ~ native+2 | 11 | 10 | **91%** | 1b24A01 t1_cond（2.21）|
| native+3 ~ native+5 | 6 | 5 | **83%** | 1b24A01 t2_pos（2.13）|
| **target ≥ native+6** | 5 | 2 | **40%** | 1BC8（5.45）、1b24A01（4.58）、1UBQ（2.54）|

### 2.3 极端正电失败现象（v5→v6→v7 演变，target = native+8）

| PDB | L | native | target | v5 dev | v6 dev | v7 dev | v7 生成均值 |
|-----|---|--------|--------|--------|--------|--------|-----------|
| 2LZM | 164 | +7.8 | +16 | 6.71 | 2.36 | **1.07** ✅ | +17.1 |
| 1CRN | 46 | −0.7 | +7 | 2.98 | 0.78 | **1.61** ✅ | +5.4 |
| 1UBQ | 76 | 0.0 | +8 | 6.55 | 1.79 | **2.54** ❌ | +5.5 |
| 1b24A01 | 95 | +8.0 | +16 | 6.10 | 5.83 | **4.58** ❌ | +20.6 |
| 1BC8 | 93 | +8.9 | +17 | 1.80 | 4.57 | **5.45** ❌ | +22.5 |

**现象**：① 失败模式是**过冲**（生成电荷 > target，1BC8 +22.5 vs +17），不是欠调；② 大蛋白/天然富碱性骨架（2LZM L=164、1CRN crambin 富 K/R）**能**外推成功；③ 小骨架 + 超高正电密度（>0.15 电荷/残基）基本失败。

## 三、原因分析

### 3.1 根因：条件组合的分布外（不是样本量不足）

训练数据中，"骨架类型"与"target 电荷"是**强耦合**的：每个训练样本的 target = 该骨架自身的 native ± 扰动（≤8）。因此：

- 模型**见过**"碱性骨架 → 高正电 target"（大量碱性域，v7 补了 678 个外部碱性域）
- 模型**没见过**"中性/弱酸小骨架 → 极高正电 target"这个组合（训练集里这种样本近乎为零）

当用户对 1BC8（native +8.9）要求 target +17，本质是要求"把本已偏碱的小骨架改造成双倍正电"——这个组合在训练分布外，模型只能**线性外推条件向量**（电荷维度从 +1σ 推到 +2σ），且解码时无约束地堆叠 K/R → 过冲。

2LZM 达标恰好因为它本身是碱性大蛋白（target +16 = 密度 0.098，在训练见过的"碱性骨架高正电"范围内）。

### 3.2 正/负电不对称：负电外推可靠，正电外推难

- **负电方向**（target 低于 native 3~8）：v5–v7 共 22 个判据，21 个达标（**95%**）。原因：① 训练分布中酸/中性蛋白占 68%，负电富集骨架（D/E 含量高）普遍；② 负电外推不违反"骨架可容纳"的物理限制——把现有序列替换成更多酸性残基相对容易。
- **正电方向**：训练分布中强碱性蛋白占比低（CATH 结构性稀疏，v7 前 +15~+20 仅 76 域），且正电堆叠受**骨架物理容纳限制**——小骨架表面可暴露的碱性位点有限，target 密度过高时模型只能过度替换 → 过冲 + 折叠退化。

### 3.3 物理限制（生物本质）

净电荷不是独立自由度：序列长度限制了可同时承载的净正电荷（表面暴露 + 静电排斥）。本模型在 target 密度 >0.15 电荷/残基时系统性过冲——这**部分反映了真实物理约束**（"小蛋白堆满 K/R"本身很难稳定折叠），但模型把它放大成了过冲。

## 四、对"绝大多数蛋白没有问题"的论证

1. **天然蛋白的电荷分布**：训练集 7,886 域中 92% 落在 [−15, +15]。若用户的设计目标**沿目标蛋白自身的电荷设定**（或 ±5 内调节），必然落在可靠区。
2. **复验覆盖正/中/负三类蛋白**：1BC8（+8.9）、2LZM（+7.8）、1b24A01（+8.0）为正电；1UBQ（0.0）、1CRN（−0.7）为中性/弱酸。在 `target ≈ native` 时命中率 91–100%。
3. **折叠（H1）在可靠区稳定**：v7 中 1UBQ/2LZM/1BC8 全 6/6 臂 H1 通过（TM 中位 0.95+）；折叠退化仅出现在 1CRN（L=46 极端小蛋白，native ESMFold pLDDT 48.7 本身边缘）和 1b24A01（域外弱折叠蛋白）——**与电荷条件关系不大，是蛋白本身特性**。
4. **负电设计（降低 pI）始终可靠**：v5–v7 负电臂全部命中（除 2LZM v5 一次 2.82，v6/v7 修复）。

## 五、使用建议

| 场景 | 推荐做法 |
|------|---------|
| 设计"pH 感知"新序列（目标 1）| 用 `target = native 电荷`，位于可靠区 ✅ |
| 降低 pI / 负电化 | `target = native − 3~8`，可靠 ✅ |
| 温和正电化（目标 2）| `target = native + 3~5`，用后检查 ✅/⚠️ |
| **大幅正电化（> native+5）** | **避免**；确需时优先选大骨架/天然碱性蛋白，并对结果做电荷复算 🔴 |
| 极端负电（< native−10）| **未充分测试**（v5–v7 只测到 native−8），建议保守并检查 |

## 六、补充：极端的定义与本模型无关的限制

- **pH 条件本身**不受限：8 个 pH 条件（4.0–10.0）训练覆盖完整，pH 响应在可靠区内单调可靠（E1b 验证）。
- **负电聚集物理**：H3 结构过滤器对负电富集序列（t2_neg）违规率偏高（1CRN/1UBQ t2_neg），属过滤器判据问题，非生成问题（见 v7 报告 §4）。
- **小蛋白折叠保真**：L<50 的极端小蛋白（如 1CRN）ESMFold 本身置信度低，折叠判据（H1）解读需谨慎。
- **蛋白规模**（配体验证补充）：条件化电荷控制还受**蛋白规模**约束——单体 L≤~300 可靠；**大蛋白（L>400）/多链电荷失配**（3T0F 双链 L=618 target −15.2 → 生成 −36.5，dev 21）。训练数据全为 CATH 单体域所致。详见 `2026-08-18_ligand_binding_capacity.md`。
- **配体复合物场景**：条件化会降低结合位点 recovery（0.62→0.41、0.71→0.58），**固定结合位点残基（--fixed_residues）可完全规避**（电荷命中 + 口袋 100% 保持，已验证）。

## 七、后续方向（治本，已在 v8 计划）

极端正电过冲根因 = "碱性 target 与骨架类型未解耦"。v8 方案：**训练时把 perturb 与骨架 native 解耦**（对任意骨架施加与自身 native 无关的随机正/负 target），让"中性骨架+高正电 target"成为训练分布内的组合——预期可扩大可靠区至 [native−10, native+10]。
