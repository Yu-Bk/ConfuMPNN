# Phase 3 防失控扩样本（n=20）—— 推翻 n=5 假阴性 + 判断标准 v1

> 日期：2026-08-16（第十三轮）
> 背景：Phase 3 防失控此前在 n=5 下判 PASS（`2026-08-16_phase3_antidrift.md`）。本报告把样本扩到 n=20 并采用**对称配对设计**，验证 PASS 是否成立。
> 结论先行：**n=5 的 PASS 是统计功效不足的假阴性**——n=20 配对检验 32 组中 23 组显著，条件注入系统性降低可溶性/热稳定。但按用户纠正后的**判断标准 v1**（`index/DESIGN_CRITERIA.md`）重新评估：结构自洽 H1 ✅、电荷命中 H2 ⚠️、注入选择性 S1 ❌。

---

## 一、方法与协议（防过拟合四道防线）

1. **泄漏检查**：验证 PDB（1BC8/1CRN/1UBQ/2LZM）的 CATH 域 ID 均不在训练域列表（`labels.npz` 999 域）——dompdb 目录里的 `1crnA00` 已下载但未抽样进训练集，**无泄漏**。
2. **对称配对**（`phase3_antidrift_extend.py`）：同一 seed → 同一 `randn` → 同一解码顺序；基线（MoMPNN 无注入）vs 条件（finetune_t05 注入）唯一差异 = 条件本身。
3. **固定 seed 协议**：seed = 111+k（k=0..19），temperature=0.3，所有 PDB/场景/臂共用，杜绝选择偏差。
4. **双场景**：A 温和（pH 7.4, target=原生电荷）+ B 压力（pH 4.0, target=原生+5）。

**样本**：4 PDB × 4 臂（A/B × base/cond）× 20 = **320 条**。
**打分**：`phase3_antidrift_n20_score.sh`（ESMFold pLDDT + 回折、USalign TM、Protein-Sol %sol、TemBERTure Tm，递归扫描 16 臂）。
**统计**：`phase3_antidrift_n20_stats.py`（配对 t + Wilcoxon + BH-FDR，32 组）。

## 二、结果

### 2.1 配对主检验（条件 vs 基线，n=20/组）

| 指标 | 显著组数/8 | Δ 幅度 | 判定 |
|------|-----------|--------|------|
| %sol | 6/8 | -4 ~ -24 分（1CRN/1UBQ 最重）| ❌ 系统性下降 |
| Tm | 7/8 | -2.5 ~ -7.1°C | ❌ 系统性下降 |
| pLDDT | 2/8 | 1BC8 -5.2、2LZM -4.4 | ⚠️ 部分下降 |
| TM-score | 6/8 | -0.007 ~ -0.074 | ✅ 幅度小（结构保持）|

32 组中 23 组 FDR-p<0.05。**此前 n=5"在噪声内"（std 7.9/6.2）是功效不足**。

### 2.2 机制（序列级证据）

条件注入改变 **>50% 位点**（1BC8 50/93、1UBQ 44/76），且为非保守替换：
- `R→I`、`K→P`（正电→疏水）、`E→T`、`D→N`（带电→中性）
- A 场景（target=原生电荷）电荷仍大幅漂移（seed_113: -6→+16）

**结论**：电荷目标命中（增益≈1）但以牺牲可设计性为代价——模型"蛮力改写序列到电荷目标"，非保守微调。

## 四、概念纠正（用户）

逆折叠本质 = **骨架固定、序列可重写**。序列大改是**设计行为**，不是破坏。"改了 pI 还要求序列与原蛋白相似"才是不合理的要求——pI 由序列决定。%sol/Tm 下降是**设计权衡**（如低 pH 高正电天然可溶差），不是失控；除非破坏源自折叠不回骨架。
