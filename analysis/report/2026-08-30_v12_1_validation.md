# 分析报告 — v12.1 闭环诊断 + 泛化验证：组成健康 + 折叠安全 + 负向可靠（2026-08-30）

> **背景**：v12 治删减成功但过度添加（slope 1.85，D/K 1.5~2× native）→ v12.1 调参（frac_floor 0.8→0.5、gravy_margin 0.15→0.4、λ_v12 0.3→0.2）→ 闭环诊断 + 校准 + 泛化验证（H1/H2/GRAVY/H4 多判据）。
> **一句话结论**：**v12.1 成功根治"过度添加"（组成 D/K 收敛到 native），校准把 slope 从 1.82 修到 1.04；泛化验证 H1 折叠 8/10 健康蛋白全过（监督没伤折叠）、负向电荷 8/10 大幅改善、H4 物理复核 6/8（仅长蛋白 1A65 欠冲）；剩余短板=正向电荷（p2/p8 3/10）。**

## 1. 闭环诊断（17 蛋白响应曲线，2026-08-30 凌晨）

**v12.1 未校准 slope 未达标**：valid 区内 **1.82 ± 0.69**（v12 1.85，几乎没动）；最坏 1BJ4 3.41、2uv8A05 2.70、1AS2 2.54。

**但组成大幅改善**（compare_comp_v121.py，5 蛋白 D/K 总数）：

**根因再确认**：slope 是 **ConditionEncoder 响应增益**（target→电荷 映射斜率），训练侧组成/GRAVY 监督不碰它 → **v12.1 的 slope 未达标与训练充分度无关，扩大训练轮次无意义**（证据：校准零重训即修复）。
