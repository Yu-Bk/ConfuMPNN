# v12.3 响应弯曲根因分析（未校准 diag 曲线，2026-09-03）

> **目的**：解释 v12.3 校准后 H2（per-protein 49% / global 40%）低于 v12.2（72%）的根因——不改评测口径，
> 纯证据。**结论：v12.3 模型未校准响应全面更 S 弯曲（非线性更强），线性校准表的线性假设更不成立 → 校准后偏差大。
> 唯一例外 1BJ4（v12.3 反而更线性）→ 其校准命中从 v12.2[0/5] 改善到 v12.3[5/5]。**
> 证据 json：`output/v12_3_response_curvature_analysis.json`。

## 一、方法
对 v12.2 与 v12.3 共有的 14 蛋白（7 trainish + 7 valid），用未校准 diag 响应曲线（`output/v12_2_diag_response.json` /
`output/v12_3_diag_response.json`）：
- **分段斜率**：grid target [-34,-25,-15,-5,0,5,18] 相邻段实际斜率（Δcharge/Δtarget）
- **bend（弯曲度）**：相邻分段斜率最大差值（越大 = S 形越明显）
- **RMSE**：观测 mean_charge 相对全靶线性拟合线（slope/intercept 来自 diag）的残差 RMSE
- **intercept**：线性拟合截距

## 二、核心结果（所有 14 蛋白 v12.3 更弯）
| 蛋白 | bend v12.2→v12.3 | RMSE v12.2→v12.3 | intercept v12.2→v12.3 |
|---|---|---|---|
| 1AS2 | 0.80→1.77 | 1.53→3.33 | −3.6→−4.1 |
| 1l3eB00 | 0.81→1.73 | 2.12→5.76 | −1.0→−2.3 |
| 1d5yB03 | 0.92→1.47 | 3.39→5.42 | −3.4→−4.5 |
| 1A65 | 0.90→1.37 | 2.05→4.64 | −4.3→−9.6 |
| 2FEO | 0.68→1.33 | 1.76→2.72 | −6.3→−7.6 |
| 5CQH | 0.52→1.29 | 1.21→2.59 | −3.2→−5.5 |
| 2uv8A05 | 0.42→1.26 | 0.89→2.68 | −5.8→−12.1 |
| 1AZM | 0.40→1.03 | 0.98→2.48 | −2.4→−4.1 |
| 1CGE | 0.18→0.87 | 0.59→1.73 | −2.6→−2.6 |
| **1BJ4** | **0.73→1.19** | **3.00→2.86** | **+5.2→−2.7** |
- **bend 全部上升**（Δ+0.4~+1.0）；RMSE 除 1BJ4 外全部上升（更偏离线性拟合）。
- **1BJ4 是唯一 RMSE 下降的蛋白**（3.00→2.86）且 intercept 从极端 +5.2 回到 −2.7（响应居中）——v12.3 的 1BJ4
  未校准响应更线性 → 线性校准有效 → 校准后命中 0/5→5/5。
- 所有蛋白 **intercept 更负**（中低 target 区模型输出系统性更负；1BJ4 例外从 +5.2 收敛到 −2.7）。

## 三、v12.3 响应更弯的机理推断
v12.3 = v12.2 + 455 长蛋白域 + 40ep（vs 30ep）。长蛋白域 native 电荷绝对值大（负电富集），训练分布加宽后，
ConditionEncoder 对**极端 target 区**（-34~-25）响应增强（分段斜率在该区常 >2，如 1A65 -25→-15 段 2.25），
而**中低 target 区**（0 附近）响应偏弱且更负 → S 形更明显。40ep 让这种"极端敏感"学得更充分 → 非线性更强。
**后果**：线性校准表（全靶单 slope）无法同时校正极端区过冲 + 中区欠冲，校准后 dev 分散大。

## 四、H2 三档（口径严格一致，无二次校准）
| 口径 | H2 |
|---|---|
| per-protein 线性表（auto） | **22/45 = 49%** |
| global 线性表 | 18/45 = 40% |
| 敏感性（去掉最弯 3 valid: 1AS2/1A65/2FEO） | per 16/30 = 53%，global 9/30 = 30% |
- 去掉最弯蛋白后 per 仅回升至 ~50%，global 反降 → **H2 偏低是普遍性**（v12.3 多数蛋白更弯），非少数蛋白拖累。
- v12.2 同口径 per-protein = 72% 作基准（v12.2 校准表对 v12.2 模型成立，因其响应更线性）。

## 五、结论（证据层面，不下交付决策）
1. v12.3 训练**改善未校准响应增益**（valid slope 1.496 vs 1.562）但**付出非线性加剧的代价**（更 S 弯曲）——
   线性校准框架下整体 H2 反而低于 v12.2。
2. **1BJ4（长蛋白）是明确正面信号**：未校准响应更线性 + 校准命中 0/5→5/5（v12.2 slope 2.49/intercept +5.2 病态 →
   v12.3 2.05/−2.7 居中）——补长蛋白对该蛋白有效。
3. 1A65（长蛋白）v12.3 响应极端负区过冲更强（-25→-15 段 slope 2.25）+ intercept −9.6 → per-protein 校准 native(−27)
   反推到响应平缓区 → 欠冲 dev +5.4（v12.2 intercept −4.3 恰好反推到陡区命中）——**校准落点敏感，非模型能力单纯退化**。
4. 若保留 v12.3，需解决"线性校准对 S 弯曲响应"的方法问题（分段/局部线性、非参数校准），但那是新口径，超本报告范围。
