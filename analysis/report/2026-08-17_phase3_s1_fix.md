# Phase 3 训练修正（第十四轮）—— 治 S1 注入选择性：perturb 0.3 + 序列保持正则

> 日期：2026-08-17
> 背景：第十三轮按判断标准 v1（`index/DESIGN_CRITERIA.md`）评估，S1 注入选择性明确失败
> （A 场景 target=原生电荷时条件臂仍重写 >50% 位点，identity 仅 0.45–0.59）。
> 本轮做训练侧修正（原生标签 50%→70% + 新增 seq-keep 序列保持正则），重训后 n=20 复验。
> 结论先行：**部分成功**——H1 结构自洽全达标且优于上轮（折叠失败 0%、pLDDT 掉落大幅修复）、
> H2 3/4 PDB 达标、S1 提升但未达 0.7 阈值；%sol 仍系统性下降（按判断标准属设计权衡）。

---

## 一、S1 失败机制与修正设计

**机制**（第十三轮序列级证据）：训练混合目标 50% 扰动样本（target=native±Uniform[1,4]）教会模型
"见电荷条件就重写"；现有 KL 锚只约束**分布距离**（softmax 概率 0.30→0.29 时 KL 已很小，但
argmax 可能翻盘 K→R），管不住序列级 identity 下降。

**修正两板斧**（`code/train_finetune.py` + `code/src/losses.py`）：

| 修正 | 内容 | 作用 |
|------|------|------|
| A. 扰动比例 | `--perturb_prob` 0.5→**0.3**（原生标签 70%） | "target=原生时保持"成主导训练信号 |
| B. seq-keep 正则 | 新增 `--lambda_keep`(0.5)；以**无条件 argmax 序列**为锚，对**自洽样本**做 `CE(logits_cond, anchor)` | 条件输出逐位逼近无条件输出 = **S1 判据的训练侧直接对应**（比 KL 更直接：管住 argmax 翻盘） |

**新损失**：`L = CE + λ_c·charge_deviation + λ_kl·KL + λ_keep·SeqKeep`
（seq-keep 只在自洽样本施加，扰动样本允许电荷偏移）

**Bug 修复**：`featurize` 返回的 `S` 带 batch 维 `[1,L]`，`torch.where` 把 `[L]` 锚广播成 `[1,L]`
导致 gather 维度错误 → `dom["S"][0]` 取单链索引修复。

| 判据 | 结果 | 详情 |
|------|:---:|------|

### 3.3 关键机制解读

1. **pLDDT 掉落大幅修复**：seq-keep 让条件注入输出贴近无条件输出 → 结构完整性大幅改善
   （2LZM −4.4→−1.1）。这是本轮最大收获。
2. **%sol 仍 8/8 显著下降**：A 场景（target=native）也降（1BC8 −13.1）→ 残余重写代价
   （identity 未到 0.7）+ B 场景电荷目标本身的张力（pH4 高正电天然可溶差，判断标准 v1 第 4 条设计权衡）。
3. **电荷偏移能力保留**：seq-keep 只约束自洽样本，扰动样本仍能调电荷（6/8 命中 target）。
4. **B 场景条件有效性**：1UBQ B base +7.73→cond +3.79（拉向 target +5）、2LZM B base +21.41→
   cond +19.45（仍过冲）；1CRN B cond +2.45 低于 target +4（轻微欠调）。

## 四、结论与下一步

**结论**：修正方向正确，收益显著但未完全达标。
- ✅ **H1 全面达标且优于上轮**（折叠失败归零、pLDDT 大幅改善、Tm 半数恢复）——seq-keep 有效保护了结构完整性
- ⚠️ **S1 提升但未达 0.7**（0.45–0.59 → 0.52–0.67）——λ_keep=0.5 力度仍不足
- ⚠️ **2LZM 过冲**（H2 老问题）——per-PDB 处理
- ❓ **H3 未测**；%sol 下降为设计权衡（不判 FAIL）

**下一步（2026-08-18 起）**：
1. **S1 再加压**：`--lambda_keep 0.5 → 1.5~2.0` 重训（扰动样本不受约束，电荷能力应保留）
2. **2LZM per-PDB 过冲**：`--charge_temp` per-PDB 调参或接受 ±2 容差
3. **H3 结构过滤器验证**：条件臂序列过 `structure_aware_filter`，比对基线违规率（≤+5pp）
4. **R1 天然蛋白对参照**：CATH 同 superfamily 找"骨架相似 pI 不同"蛋白对，验证目标可达
5. 若 λ_keep 提不上去：考虑 `--fixed_residues` 位点固定对照臂（与 seq-keep 互补）
