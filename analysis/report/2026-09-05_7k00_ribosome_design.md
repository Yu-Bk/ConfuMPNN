# 7K00（E. coli 70S 核糖体）天然核糖体蛋白 — v14 配体模式可设计性测试（2026-09-05）

> 目的：用 PDB 7K00（E. coli MRE600 70S，cryo-EM 1.98 Å，56 聚合体）拆出天然核糖体蛋白，
> 测 v14 配体模式在 **native / 温和(±2)** 电荷臂下的可设计性，并与测试集核糖体蛋白 5O60_E 对照。
> 本测试不做 ESMFold/Tm-Sol（保持轻量）。

## 一、方法与口径

| 项 | 值 |
|---|---|
| 结构 | PDB **7K00**，标题 'Structure of the Bacterial Ribosome at 2 Angstrom Resolution'；cryo-EM 1.98Å；`_entity_src_nat.pdbx_organism_scientific`='Escherichia coli'（MRE600，NCBI 562）。56 聚合体 = 16S/23S/5S rRNA + 49 核糖体蛋白 + mRNA + A/P/E tRNA |
| 拆分 | `output/ribosome_7k00/split_7k00.py`（复用训练集 `split_nucleic_complex.py` 同款策略：蛋白单链 + 15Å 邻近**核酸聚合物**作配体上下文，仿 `data/validation_pdbs/5O60_E.pdb`；蛋白重标 A、核酸重标 Z；parse_PDB QC mask≥0.9） |
| 过滤 | 长度 [50,500]（训练集同款）→ 剔除 L9（L=41，部分建模/破碎）、L34（L=46）、L36（L=38） |
| 去重 | 46 链序列两两 100% 重复 = 0（70S 单拷贝，无内部重复） |
| 建集 | `output/ribosome_7k00/manifest_7k00.json`（46 items，cat=RNA）+ `protein_labels.json`（L/native seq/native_charge@7.4） |
| 模型 | v14 编码器 `output/finetune_ligand_v14_rna/finetune_epoch050.pt` + 骨架 `LigandMPNN/model_params/ligandmpnn_v_32_010_25.pt`（atom25） |
| 采样 | `validate_generalization.py`，n=50/臂，臂 = native/n2/p2，pH 7.4，temperature 0.3 |
| 校准 | 蛋白不在 v14 校准表 → **global** `charge_calibration_v14_ligand_clean.json`（slope 1.492 / intercept −1.260），`--calibrate global` |
| 判据 | H2 = 每臂 \|mean_charge − target\| ≤ 2；带电保留率 = native 臂生成序列 (D+E+K+R)/native (D+E+K+R) |
| GPU | cuda:4（共享，他人 gmx；03:30→04:34，64 min），日志 `log/ribosome_7k00_val_sample.log` |

## 二、汇总结果

| 臂 | H2 通过 | H2 率 | mean dev | median dev | max dev |
|---|---|---|---|---|---|
| native | 26/46 | 56.5% | 2.31 | 1.90 | 12.86 |
| n2 (Δ−2) | 25/46 | 54.3% | 2.18 | 1.71 | 11.62 |
| p2 (Δ+2) | 23/46 | 50.0% | 2.55 | 2.01 | 13.63 |

- **native 臂带电保留率**：mean **0.645**（median 0.602，range 0.387–1.183）；33/46 蛋白 <0.7 → 多数蛋白上模型仍系统性**删除带电残基**（删减捷径未根治）。
- 全 3 臂都 H2 达标的蛋白 **19/46（41%）**；3 臂全不达标 **16/46（35%）**；其余 11 个部分达标。

## 五、结论

1. **整体可设计性中等偏弱**：46 个天然 E. coli 70S 核糖体蛋白在 v14 配体模式下、native/±2 电荷臂，
   H2(\|dev\|≤2) 仅 **50–57%**（native 26/46、n2 25/46、p2 23/46），全 3 臂通过仅 19/46（41%）。
   相比测试集内核糖体蛋白 5O60_E（native/±2 全达标，dev≈1）与 in-10 全验证集（90%），本组明显更差 →
   **v14 配体模式在天然强正电核糖体蛋白上的电荷控制并不可靠**。

2. **失败集中在高电荷密度/强碱蛋白**，方向主要是**正向过冲**（L15 +16→+23、L19 +12→+18、L2 +32→+38、
   L20 +24→+29、L4 +8→+12、L3/S3 等）：生成序列净电荷显著高于 target，接近模型响应饱和区
   （校准表 global 有效训练 target 最高约 +18，而 L2/L20/S12/L35 等 native 达 +19~+32，处外推区）。
   极端反例 S21（L=70、native +13.9，电荷密度 ~0.2/残基）严重**欠冲**（dev 11.6–13.6，生成仅 ~+0.4~+2.4）。

3. **温和负向 n2 是否触发删减**：整体与 native 相当（H2 25/46，median dev 1.71，三臂中最好），
   未出现"温和负向系统性崩坏"；但唯一 native 为负的 S6（−1.8）在 n2（target −4）欠冲 dev 2.57 → 轻微负向仍偏保守。

4. **带电保留率（删减判断）**：native 臂 mean 0.645，33/46 <0.7 → 模型仍普遍**删除带电残基**（与 v14 配体已知
   删减捷径一致，5O60_E 亦 0.56）。但强过冲蛋白保留率反而较高（L2 0.97/L15 0.86/L19 0.88/L20 1.18）→
   这些蛋白的偏差主要不是删减，而是**无法精确设定高正电目标**（保留碱性残基、删酸性残基/净电荷仍超调）。

5. **H4/H1/Tm-Sol 未测**（按要求轻量），本报告仅覆盖电荷可设计性与组成维度。

### 局限与备注
- 使用 **global 校准**（46 蛋白均不在校准表内）；per-protein 小样本现场标定或可改善，未测。
- S6 是唯一 native 负电蛋白（−1.8），单列不污染"正电核糖体蛋白"主结论。
- 拆分仅保留核酸（rRNA/tRNA/mRNA）作配体，排除离子/抗生素；训练集拆分含离子，口径略不同但主结论不受影响。
