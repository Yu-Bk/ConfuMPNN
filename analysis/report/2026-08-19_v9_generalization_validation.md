# v9 泛化验证报告 — 10 未见蛋白 × 5 电荷臂 × 配体消融

> 日期：2026-08-19
> 背景：v9（LigandMPNN backbone + 配体原子上下文 + 重训条件编码器）训练成功（`2026-08-18_v9_ligand_training.md`），
> 但仅验证了 3 个蛋白（1MBN/4DFR/1FQG）。本报告系统检验**泛化能力**：10 个训练/验证范围外的蛋白、
> 5 档电荷目标（native/±2/±8）、每档 30 条序列、ligand（有配体上下文）与 protein（无配体）双模式。
> 计划：`index/PROJECT_V9_GENERALIZATION_PLAN.md`；判据：`index/DESIGN_CRITERIA.md` v2（H2 dev≤2.0、H1 TM≥0.70、失败率≤10%）。

---

## 一、结论先行

1. **折叠（H1）泛化良好**：10 个蛋白中 **7 个 native 自洽蛋白的 56 个臂全部折回原骨架**（TM 中位 0.90–0.99，失败率 0%）。另有 3 个蛋白（1C6O 血红素、1AG0 含 Cu、1AXW L=528 大蛋白）**native 序列自身 ESMFold 回折 TM 仅 ~0.5**——不是模型问题，是 ESMFold 对这类含辅因子/大蛋白的不确定性，H1 判据对其不适用（电荷判据仍有效）。
2. **电荷控制（H2）温和区可靠、极端负电是弱项**：中短蛋白（L≤312）温和区（native±2）达标 **87%**、极端正电 +8 达标 **100%**、但**极端负电 −8 仅 40%**（欠冲）。这与 v7（MoMPNN）"负电强、正电弱"相反——**v9 配体模式的新泛化边界**。
3. **配体上下文贡献不显著且因蛋白而异**：无系统性帮助；在 L=504 大蛋白 1A65 上配体上下文**明显有害**（电荷 dev 5.24 vs 无配体 0.54）。
4. **两类系统性失败蛋白**：① 长序列蛋白（1A65 L=504、1BJ4 L=470）全臂欠达标；② 1C6O（血红素）电荷控制与折叠双失败。

**总体达标**：H2 44/80 臂（55%，含 3 个问题蛋白拉低）；剔除 ESMFold 不自洽蛋白后，健康蛋白温和区 13/15（87%）。

### 3.3 关键结论

- **温和区（native±2）**：中短蛋白 87% 达标，**日常使用可靠**（与 v9 训练验证一致）。
- **极端正电 +8 反而是强项**：中短蛋白 5/5 全达标（1AZM +6 dev 0.76、1CGE +4 dev 0.44、2FEO +1 dev 0.15）。**v9 在配体模式下极端正电控制优于 v7 MoMPNN**（v7 报告 >native+5 仅 40%）。
- **极端负电 −8 是弱项**：中短蛋白仅 40%，失败模式为**欠冲**（生成电荷不够负：1AS2 target −11 → −8.67、1CGE target −20 → −16.47、5CQH target −14 → −11.75）。**v7"负电可靠 95%"的优势在 v9 配体模式丢失**。

> 推测原因：v9 训练数据（配体复合物）中极端负电 target 覆盖弱于 MoMPNN 训练集，且配体上下文可能在解码时稀释了条件编码器注入的负电信号（详见消融 §5）。

- **折叠受配体影响小**（健康蛋白两模式 TM 均 ≥0.9）。

## 六、失败模式与边界（诚实呈现）

### 6.1 长序列蛋白（L≥470）全臂欠达标

- **1A65**（L=504，NAG 糖配体）：ligand 全臂欠冲（−4.7~−6.7），无配体后恢复 → **配体干扰**是主因。
- **1BJ4**（L=470，PLP 转氨酶，native 近中性 +0.42）：全臂略欠（dev 2.0–3.2），**p8 正电过冲到 +14（target +8）**→ 近中性大骨架的正电化困难，与 v7"小中性骨架正电过冲"同型，但发生在 L=470。
- 两蛋白 **折叠均完好**（TM 0.91–0.97）——电荷控制失败不影响折叠，是"条件 vs 结构"的张力。

### 6.2 血红素蛋白 1C6O 双失败

- 电荷全臂欠冲（dev 3.1–7.6）+ ESMFold 不可靠（native TM 0.5）。
- 1C6O recovery 0.57（高），native 电荷已 −14.3（富酸），target −22 需要大幅增加 D/E——模型倾向于保持 native 残基而欠冲。可能反映血红素结合对序列疏水/结构约束强，表面可酸性化位点受限。

### 6.3 与 v7 电荷可靠范围的对比（`2026-08-18_model_charge_limits.md`）

| 条件 | v7（MoMPNN，小蛋白） | v9（配体模式） |
|------|---------------------|---------------|
| 温和 native±2 | 91–100% | 87%（中短蛋白）|
| 极端负电 −8 | **95%** | **40%（欠冲）** |
| 极端正电 +8 | 40%（过冲）| **100%（中短蛋白）** |

**v9 反转了 v7 的正负电不对称**：配体模式下负电外推变弱、正电外推变强。使用 v9 时应遵循新边界：**正电设计可用到 +8，负电设计保守到 −5**。

## 七、结论与使用建议

1. **v9 折叠泛化可靠**（健康蛋白 H1 100%），配体上下文不破坏折叠。
2. **电荷控制的可靠范围（配体模式，中短蛋白 L≤312）**：
   - ✅ 温和区 native±2：可靠（87%）
   - ✅ 极端正电 target = native+8：可靠（100%）
   - ⚠️ 极端负电 target = native−8：**欠冲**（40%），建议保守到 −5 并检查结果
3. **长序列（L≥470）/ 血红素类蛋白**：电荷控制不达标，需检查；若配体干扰明显（如 1A65），可考虑无配体模式或固定结合位点。
4. **配体上下文**：不是电荷控制的必要条件，大蛋白上反而有害；若要在配体模式下做电荷设计，优先选中小蛋白。
