## 一、训练修正（第十七轮）

| 修改 | 第十六轮 | 第十七轮 | 治什么 |
|------|---------|---------|--------|
| 占位符语义 | 两种各半：flag=0+值0 / flag=1+均值 | **统一均值占位**（has_charge=1+值=训练均值 −1.34）| 符合目标 2"部分条件不控制用**非 0 占位符**替代" |
| 占位样本电荷损失 | **跳过** | **施加**（target=训练均值）| 让"占位"落在温和可折叠默认，而非放任漂移 |

> 第十六轮根因（实证）：占位样本跳过电荷损失 → 模型学"维度不控制" → seq-keep 锚定无条件 argmax
> （本身负漂移基线：1BC8 −9.66/2LZM −6.32/1UBQ −3.46）→ 推理占位时电荷极端负极化（−8~−16，D+E 占 18–36%）→ 折叠全失败。

## 七、剩余问题与下一步

**唯一残余：正电过冲（1BC8/2LZM，正电富集蛋白）**。即使 target 温和化（+3），这两个 native
本身 +8/+9 高正电的蛋白往更高正电外推时模型仍过冲（dev 4.6/7.4）。与训练数据分布偏负（CATH S40 均值 −1.34）
一致——模型对高正电区域欠拟合。

**可选修复方向**（下一轮，若需要）：
1. **训练域补正电富集蛋白**：在 CATH S40 里筛选 native 净电荷 > +5 的结构域加入训练集，扩大正电覆盖。
2. **训练扰动偏向正电**：扰动 offset 正方向概率/幅度加大（当前 ±Uniform[1,8] 对称），让高正电 target 更常见。
3. **推理侧正电校准**：对 target_charge > +5 的输入单独启用 per-PDB 校准（当前全局关闭，因会过校正）。

**对两个真实目标的结论**：
- **目标 1（天然骨架→全新序列+pI≈天然）**：✅ 已验证成立。H1 折叠 4/4、S4 位点固定 100%、pI 命中 2/4
  （1BC8/2LZM 微超 2.4–2.8，属正电残余问题）。
- **目标 2（人工骨架→全新序列+简单理化预期）**：✅ 核心能力成立。负电/中性目标 4/4 精确命中 + 折叠良好；
  **占位符（不控制）已修复为可折叠的温和默认**——"部分条件不控制用非 0 占位符"这条路径打通。
