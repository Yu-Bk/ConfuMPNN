# v14 组成删减定位分析（Task1, 2026-09-04）
Deletion-location analysis of charged residues in v14 ligand-mode native-arm generations

## 0. 方法与口径 / Methods
- **零新采样**：只用已有 `output/generalization_ligand_v14_clean/ligand/<pdb>/pH7.4/arm_native/seqs.fa`（native + 50 生成/native-arm）与参考结构 `data/validation_pdbs/<pdb>.pdb`（v14 `ref/*_ref.pdb` 只含 N/CA/C 骨架、无配体，故 pocket/SASA 用 validation PDB）。
- 带电残基 = **D/E + K/R**（与研究既有 `compare_comp` 口径一致）；保留率/删减倍率 = **生成 50 序列均值 / native 计数**（native=0 → NaN）。
- **三区（互斥）**：`pocket`= 残基 Cα 距任一配体重原子 ≤ 8 Å；`surface`= 其余且 frac_sasa ≥ 0.25；`core`= 其余。SASA 用 `freesasa` fractional SASA（全结构含核酸/配体）。
- 判别特征：pool 全部 native 带电位点，按“同符号电荷保留率”分**重删 ≤0.6** vs **轻删 ≥0.85**；AUC = P(重删特征值 > 轻删特征值)。
- Caveat：这是 **native-arm、n≈50 生成均值**口径；删减本身是“删捷径”证据，不代表折叠后组成。RNA/DNA 新成员与 6D2O **无 v13 基线**，v13 对比只在 5 共享单体（1AS2/2FEO/5CQH/1CGE/1BJ4）上成立。

### 结论（分层）
1. **温和区 = 最重删减档**：native 与 ±2 保留率几乎无差别（DK 0.44-0.70），D/E 与 K/R 被**无差别**砍到 ~0.5× → "删总数"是微调模型的默认生成习惯，与电荷需求大小无关。
2. **极端区删减不消失，转成"方向性不对称"**：n8 保/加 D/E（0.80-1.13）但仍删 K/R（0.38-0.53）；p8 狠删 D/E（0.33-0.65）而保/加 K/R。净电荷靠"删对侧 + 保/加同侧"凑出。
3. **类别差异**：nucleotide 全程最重（极端下也照删，DK 0.42-0.72）；RNA/DNA 在"顺其自然的 + 方向"保留最好（KR 0.94-1.26）、被迫负向时删最凶（DK 0.43-0.59）；metal 极端下定向删对侧最极端（p8 D/E 0.33 / n8 加 DE 1.13）；long(1BJ4) 各档较均匀 ~0.5。
- 含义：删减捷径从**温和档即存在**，非"仅大电荷变化触发"；极端档只是将其用作净电荷的方向工具 → 佐证"全局电荷 bias 无法取代局部/结合位点保护"（对应 2025 全局-bias 论点）。
