## 4. 逐组件归因

### 4.1 B（L_add）—— 纯有害，建议弃用
- v11a（只去掉 B）是四版 valid 区内最好：1.67 → **1.41**（改善 0.26，16/17 蛋白下降）。
- v11c（加回 B-fix λ0.1/scale0.5）反而 **1.57**，比 v11a 差 0.16。
- 结合代码分析（`code/src/v10_losses.py`）：L_add 是"表面 D/E 存量 ≥ |Δ| 增量"的下限检查——高负电蛋白存量远大于增量，relu 常不激活；且删 K/R 不改变 D/E 计数，**完全不阻止删减捷径**。其存在只会给损失加噪声、干扰主目标。
- **结论：B 方向无救，应弃用**（或彻底重写为"阻止删减"对比损失，非增量下限检查）。

### 4.2 A-fix（绝对 target 采样）—— 无效甚至轻微回退
- v11b（A-fix 单开）valid 区内 1.50 > v11a 1.41，说明绝对 target 没有比相对解耦更好。
- 副作用显著：**把原本好的蛋白拖坏**——1C6O 区内从 0.98（v10/v11a，达标）恶化到 1.39/1.66（v11b/v11c）；2FEO、1AZM 也轻微变差。
- 机制解释：绝对 target ∈[−35,20] 采样使模型对所有 target 区间平均响应，等于"把大 slope 压下去的同时把小 slope 抬上来"——**只是平均化，不是校正到 1**。且训练 target 分布与推理 target 网格可能不一致，引入新的系统偏差。
- **结论：A-fix 方向无帮助**。残余过冲仍在 decouple 机制本身。

### 4.3 C-fix（逐样本 boost）—— 无帮助
- v11c（含 C-fix）1.57 > v11b（无 C）1.50，C-fix 引入未见收益（可能与 A-fix 耦合）。

### 4.4 残余过冲主因 = decouple 训练机制本身（或生成侧 bias 叠加）
- 四版中**最干净**的是 v11b（无 B、无 C、只 A-fix）——valid 区内仍 1.50。
- v11a（去 B 但留 decouple+C）1.41 是四版最好，但已无 B 可去。
- 说明：**去掉 B 和 C、换 target 采样方式，都到不了 slope≈1**。过冲的深层来源必须在"decouple 如何训练 + 生成时如何把 target 转成 bias"这条链里找：
  - 训练侧：charge_dev 是软回归（λ_c=0.5 且 30% 概率扰动），模型对 target→电荷 的记忆强度不足，解码时用 logit bias 强推，两者叠加产生 >1 的净响应。
  - 生成侧：需要查 `conditioned_sampler.py` / `guided_sampler.py` 的 bias 施加公式（是否有"每残基 bias × 残基数"累积导致的超线性）。

## 5. 对"表面电荷添加（B/L_add）能否解决"的判断

用户上一轮要求评估"有没有办法解决表面电荷添加这个问题"。本报告给出证据链：

1. **当前 L_add 实现无法解决**：逻辑上就是"存量下限检查"（已分析）；实测 v11c（B-fix 半量低权）比 v11a（无 B）差。
2. **若真要保留"表面电荷"思想**，需重写为监督**生成序列表面电荷密度/组成**的目标（例如：鼓励生成序列在表面保留带电极性残基、惩罚删减），而不是监督"表面 D/E 与目标增量的关系"。但这仍是"抑制删减捷径"的间接手段，且需新损失设计 + 重新消融（A7 系列）。
3. **更直接的方向**：既然 B 只是放大器、decouple 才是残余主因，投入应转向 **decouple/生成侧 bias 的校准**（见 §4.4），而非继续在 B 上打补丁。
