# Phase 3 防失控判据 —— 条件注入 vs MoMPNN 基线（pLDDT/TM/%sol/Tm）

> 日期：2026-08-16
> 回答用户关切：**微调（条件注入）会不会破坏溶解性/Tm/可设计性？**
> 前置：Phase 3 pH 响应 Go/No-Go 通过（`2026-08-16_phase3_pH_response.md`）

---

## 一、实验设计

- **条件注入模型**：MoMPNN（冻结）+ 微调 ConditionEncoder，pH 7.4、target=native（自洽点）、temp 0.3、8 序列/PDB
- **两套对照**：
  - `phase3_antidrift`：直接给 target=native → **电荷过冲**（1BC8 实际 +25.6 vs native +8.9）
  - `phase3_antidrift_cal`：给校准 target（`target_eff=(native+1.1)/2.9`）→ **电荷≈native**（1BC8 +8.9）
- **基线**：E1b MoMPNN baseline（`summary_cond.csv` mompnn,baseline 行，5 序列/PDB）
- 打分：ESMFold pLDDT + us-align TM-score（回折 vs 原骨架）+ Protein-Sol %sol + TemBERTure Tm

## 三、关键发现

### 1. ✅ 机制证实：pLDDT 下降主因是「电荷过冲」，非条件化本身
- 1BC8 从「过冲版 77.4」→「校准版 82.3」→「基线 82.8」：**校准后 pLDDT 恢复几乎等于基线**
- 2LZM 从 -2.6 → -1.6。即：**超高电荷（+25）序列不利折叠，电荷恢复正常后设计性恢复**
- 1CRN/1UBQ 仍有 1-4 分差距（可能与该两蛋白采样集具体序列有关，n=8 噪声）

### 2. ✅ %sol/Tm 差异在采样噪声内（非系统性退化）
- 1BC8 校准版 %sol 单值分布 std=7.9、Tm std=6.2 → **-6.9 / -3.8 的差异均在 1σ 内**
- 2LZM %sol +2.4、Tm +2.5（过冲版）——**甚至更好**。无「溶解性/Tm 崩掉」的证据
- 结论：条件注入没有把可溶/热稳推到悬崖边；差异主要是具体序列采样波动

### 3. ⚠️ 真正的待修问题：电荷校准过冲（~2.9×）
- 机制（已证实）：训练优化 softmax 期望电荷 E[Q]，推理测采样序列电荷；CE 训练使模型自信 → 采样更极端
- 缓解：① 推理侧线性校准 `target_eff=(desired+1.1)/2.9`（本文已验证有效）；② 温度 1.0-2.0（但高温度本身降 pLDDT，需权衡）；③ 训练侧改（缩小 perturb、增加 KL 锚、或在损失中用温度化电荷）

## 四、结论（防失控判据）

| 关切 | 结论 |
|------|------|
| 溶解性 %sol 是否失控 | ✅ **否**（差异在采样噪声内；2LZM 甚至更好） |
| 热稳 Tm 是否失控 | ✅ **否**（同左） |
| 可设计性 pLDDT | ⚠️ 过冲时掉 2-5 分；**校准后 1BC8/1UBQ 恢复≈基线**，TM-score（实际折叠能力）保持 0.84-0.98 |
| 结构保持 TM-score | ✅ 保持（1BC8 0.891 / 1UBQ 0.961 / 2LZM 0.976，均 >0.84） |

**Phase 3 防失控判据：PASS（有校准注意事项）。**
条件注入没有破坏 MoMPNN 的多目标可开发性；需要解决的是**电荷精确控制（校准过冲）**，这是推理侧或训练侧可修的工程问题，不是机制性缺陷。

## 五、建议下一步

1. **校准落地**：把 gain/offset 校准系数写入 `condition_defaults.yaml`，推理时自动换算 target
2. **训练侧改进（可选）**：扰动扰动范围/比例、或在 charge_deviation 损失中对 logits 加温度（直接优化「采样序列电荷」而非期望电荷）→ 一劳永逸减小过冲
3. **扩大样本**（可选）：每 PDB n=20+，压采样噪声，给 %sol/Tm 做统计检验
