## 0. 外部论点确认（2025 MPNN bias-redesign 工作）
> Global biases cannot address local sequence features that are critical for binding and developability
> （全局抑制表面电荷会连带破坏结合/稳定性关键的氢键、盐桥等局部特征）。

**本项目支持证据**：①删减捷径在**温和/零电荷需求档即存在**（native 与 ±2 无差别砍带电总数到 ~0.5×，Task1 补充分档）；②fix 结合位点只护住局部、删减**不转移也不消失**（Task2：全局"删总数"习惯仍在）；③大样本下删减仍是全局最弱环节（Task3：删减通过率 17.5% 远低于电荷 32%、H3 99.9%）；④同一删减现象跨 v12.2/v13/v14 复现（0.43-0.69×）。
→ **指导意义**：全局表面电荷 bias（无论训成 logit bias 还是条件监督）不足以保留结合/稳定性关键的局部带电残基网络；需**局部/结合位点感知**的监督、固定位保护或结构先验与之配合。**（本工作是"global bias 需 local 补充"的一个具体实例证据）**

## 1. 子结论 A（Task2 → 设计前固定关键残基）
**主张**：先做结构分析，在设计前**把 pocket 与 core 中对功能重要的带电残基固定为 native**，可防止这些位点被"删减捷径"牺牲；**且固定不导致删减转移**（非结合区删减不加重）。

**证据（v14 in-10，fix=Cα-配体≤8Å，n40）**：
- 口袋带电残基保留 0.46× → **1.00×**（构造性恢复，mismatch=0）；
- 口袋外表面 0.601→0.607、核心 0.388→0.372（**几乎不变 = 不转移**）；总量 0.53→0.675（增量全部来自被保护的 pocket）。

**必须写进论文的 scope/caveat**：
- 本实验 fix 了**全部**结合残基（占 L 的 6-54%），属"极端受控对照"；如此大范围 fix 使电荷命中 90→36%（删减是模型当时唯一的电荷杠杆，锁死后无替代机制；另含 unfix 校准失配）。
- → **实用建议是 fix 一小撮精心挑选的功能关键残基**（如参与盐桥/氢键的结合口袋带电残基 + 个别 core 关键位），而非全结合区；在大范围 fix 或需保住电荷控制的应用里，模型需补充"反号替换/新增带电残基"的监督或重新小样本标定。

## 2. 子结论 B（Task3 → 大批量设计有命中，可作实用管线）
**主张**：即使单条序列达标率低，**批量设计 + 筛选仍可获得符合要求的候选**（电荷达标 ∧ 不重删 ∧ 无聚集），因此"大批量生成→按需过滤"是可行应用范式。

**证据（v14 in-10 × 5臂 × n=200，1 万条）**：
- 逐序列"三达标"率 5.2%；n=200 时 **60% 臂（30/50）可捞到 ≥1 条**三达标；代表：1CGE n8 dev=0.11/del=0.72、3MXB_A p8 dev=0.02/del=0.90、6D2O n8 dev=0.18/del=0.71、21KL_A p8 dev=0.02/del=0.81。
- 随 n 单调可捞：三达标条数 n50→127、n200→523。

**scope/caveat**：**40% 臂（尤其长蛋白 1BJ4 全 5 臂与多个 DNA/核苷酸结合臂）在 n=200 仍为零**，属删减捷径的**系统性失败**，单纯放大采样救不回——这类（能力受限）臂需模型层面修复而非抽更多样本。故 B 表述为"存在性受限的臂可被批量救回"，而非"所有情况都行"。

## 3. 与 v13/v14 训练假设的呼应（待 v13-in10 全链完成后补）
- 中期数据已示：v13（未训 RNA/DNA）在 RNA/DNA 蛋白上删减比 v14 轻（21KL_A/5O60_E/3MXB_A 保留 0.93-0.99 vs v14 0.56-0.69）→ 佐证"系统性删减是**微调引入/强化的组成习惯**"，与子结论 A/B 及外部论点同源。
