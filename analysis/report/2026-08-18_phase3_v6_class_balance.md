## 3. 突破（相对 v5）

1. **1UBQ 中性泛化大幅恢复（1/5→4/5）**：t1_cond dev 2.40→0.70、极端正电 dev 6.55→1.79。**证实 v5 根因判断正确**——中性骨架多样性从 600→2,500 后，域外中性蛋白的"中性 target→序列"映射建立成功。这是本轮最大验证。
2. **极端正电普遍改善**：1CRN 2.98→0.78、2LZM 6.71→2.36、1UBQ 6.55→1.79——碱性域全保留（2,208 个）让模型见过更多正电骨架。
3. **H2 合计 19/25（v5 16/25）**：电荷控制整体显著进步。

## 4. 遇到的问题（诚实记录）

1. **折叠退化（H1 25/30 vs 30/30）**：
   - 1CRN：t2_neg fail 0.2、t2_ph fail 0.15（crambin 小蛋白 native pLDDT 48.7，强电荷条件+小蛋白折叠保真下降）
   - 1b24A01：t1_base TM 0.69、t2_neg fail 0.2、t2_ph fail 0.25，pLDDT 从 v5 70-76 → 58-67（域外新蛋白，无条件/占位生成折叠保真下降）
2. **1BC8 正电臂退化（5/5→3/5）**：t2_pos dev 0.46→2.28、极端 0.37→4.57。原因：三类平衡后训练重心偏向中性/温和，+15~+20 极端 target 绝对样本仍仅 76 个（逆加权 cap=2 增强有限），1BC8（native+8.9 需极高正电）受影响。
3. **H3 1CRN t2_neg 仍违规**（0.15 vs base 0.025，超 5pp）；1b24A01 t2_pos 违规率 0.202 vs 0.149 超限。

## 5. 根因分析

- **三类平衡解决中性多样性（成功）**：1UBQ 恢复证明中性骨架多样性是中性泛化的关键。
- **极端正电样本绝对量不足（残留问题）**：+15~+20 仅 76 域，即使碱性全保留+逆加权 cap=2，模型对超高正电 target 的外推仍不稳定（1BC8 极端 4.57、1b24A01 极端 5.83）。**CATH 内无法解决**——需外部补充碱性 PDB，或极端 target 课程学习。
- **折叠退化**：三类平衡后数据更均匀，但可能引入了更多"电荷驱动过激替换"的样本，对弱折叠/域外蛋白（1CRN/1b24A01）的无条件/强电荷条件保真下降。

## 6. 结论

v6 在**电荷控制**上显著进步（H2 19/25，核心目标 1UBQ 恢复、极端正电改善、目标 1 形态 5/5 全达标），但在**折叠保真**上付出代价（H1 25/30，1CRN/1b24A01 部分臂失败率超标）。是"电荷 vs 折叠"权衡的又一次移动，方向与用户"通用模型"需求一致，但 1b24A01 折叠退化需在 v7 关注。
