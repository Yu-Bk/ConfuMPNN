## 〇、执行概要（一句话结论）

**分层平衡采样 + 逆密度加权对"训练见过的正电蛋白"效果显著**：1BC8 全 6 臂命中（极端正电 +17 dev 0.37）、
2LZM 目标 1 修复（t1_cond dev 0.35）、新正电验证蛋白 1b24A01 泛化良好（4/5）；**但逆加权过头**——
cap=5.0 压坏了中性蛋白 1UBQ（0/5 命中，dev 2.5-3.2），证实文献"naive 加权牺牲频繁样本"警示。
**需调参平衡**（降低逆加权强度）再训一轮。

## 一、训练改动（第十八轮）

| 改动 | 内容 | 治什么 |
|------|------|--------|
| **分层平衡采样** | 从 34,612 域按 native 电荷@7.4 分 8 箱（−20~+20）每箱抽 100（[+15,+20) 全取 76）→ 776 域，电荷分布均匀 | 原 999 随机抽样正电稀疏（native>+10 仅 1.3%）→ 高正电 target 分布外过冲 |
| **逆密度加权** | charge loss 按 target 密度逆加权 `w=k/(density_norm+ε)`，高正电 target 权重更大（实测 +12 target 权重 6× 于中间）| 不均衡回归标准解法（US11720818B2 / arXiv 2506.01486）|
| μ/σ 重算 | 平衡集 charge mean −1.34→+1.07、std 7.78→11.99，写入 config | 数据分布变化后标准化对齐 |

## 五、核心结论

1. **分层采样 + 逆密度加权对训练见过的正电蛋白（1BC8/2LZM）效果显著**——目标 1 完全修复，
   极端正电外推从 dev 8.7 级 → 0.37（1BC8）。这是本轮最大收获。
2. **正电泛化部分成功**：新正电验证蛋白 1b24A01（native +8.0）4/5 命中——模型学会了
   对未见骨架的正电电荷控制。
3. **逆加权过头（cap=5.0）**：1UBQ（中性蛋白）全臂退化 dev 2.5-3.2——文献"naive 加权
   牺牲频繁样本"警示实锤。**cap 需降低**（如 2.0）或 k 减小，保护中性蛋白。
4. **1CRN 正电侧欠调**、2LZM 正电 target 仍过冲：高正电 target 的控制仍不完美，
   但比十七轮改善（2LZM t2_pos 3.69 vs 之前 7.41）。
5. 1a87A02 为弱验证蛋白（native 折叠置信度低），不作为泛化判据。

## 六、下一步（调参平衡）

**目标**：保留 1BC8/2LZM/1b24A01 的正电改善，恢复 1UBQ 中性蛋白命中。

候选调整：
1. **降 cap**：5.0 → 2.0（限制高正电权重过度放大，保护密度中心样本）
2. **降 k**：1.0 → 0.5（整体弱化逆加权）
3. **重训验证**：finetune_v5，复验重点看 1UBQ 恢复 + 1BC8/2LZM 正电改善保留
