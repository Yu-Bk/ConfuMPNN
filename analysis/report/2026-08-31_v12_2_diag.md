## 六、hold-out 评估（global 校准下未见域）

**设计**（`code/tests/validate_holdout.py`）：hold-out 1,176 域（从训练集划 15%，对 v12.2 真正未见，同分布）抽样 30 域 × 8 pH × n=5 = 240 样本。**global 校准**（hold-out 域不在 17 蛋白 per_protein 表内），target=round(label charge)。

**结果**（28 域成功，2 域 parse 失败跳过，224 样本）：

| 指标 | 值 |
|------|-----|
| H2 命中率（dev≤2）| **40.6%** |
| 平均 dev | 3.29 |
| 平均 recovery | 0.333 |

**对比**：per-protein 校准的泛化 10 蛋白 H2 = 58%（v12.1）。**global 校准对未见域命中率低 ~18pp**。

**解读**：
1. **global 校准是"平均化兜底"，对分布外的未见域外推精度有限**——响应增益是蛋白特异的（17 蛋白 per-protein slope 0.93-1.17，个体差异明显）
2. **recovery 0.333 低**——未见域上序列保持率低（CATH 域与完整蛋白差异 + 电荷条件偏离 native）
3. **不是 v12.2 训练缺陷，而是校准覆盖问题**：17 蛋白校准表只保证"见过域"精度；对全新域 per-protein 不可用、global 兜底不足
4. **改进方向**（需用户决策）：① 更大校准集（50-100 蛋白 → 更稳 global）② 分层校准（按 native 电荷分箱分别拟合）③ 论文如实报告"global 校准对未见域命中率 ~40%，建议对目标蛋白先做小样本校准"
5. **与 §4 判据对照**："hold-out 命中率 ≥ 训练分布内基准"——**未达标**（40.6% < 58%），是 v12.2 体系的已知限制

## 九、结论与使用指南

1. **v12.2 模型本身电荷控制能力强**：per-protein 校准下 72%、无过拟合（trainish/valid slope 相当）、slope 达标 1.00
2. **global 校准对陌生蛋白命中率 ~40-44% 是固有上限**：§6E 判据"若 big-global ≈ hold-out → 确认固有局限"**成立**（44% ≈ 40.6%）。根因 = 响应增益蛋白特异（slope 0.93-1.17），训练域平均的 global 对增益偏离的蛋白校准不足。**校准表扩到 100 域（460 点）不能改善对陌生蛋白的命中率**
3. **使用指南（论文如实报告）**：
   - 目标蛋白在 17 蛋白校准表内 → per-protein 校准（~72%）
   - 目标蛋白不在表内 → **先对目标蛋白做小样本标定**（采 20-50 条拟合它自己的 slope，相当于临时 per-protein），这是对陌生蛋白的正确用法
   - 不做标定直接用 global → 预期 40-44%（如实标注）
4. **1BJ4/2FEO 在 per-protein 下 0/5 是"高方差蛋白 n20 校准拟合过差"**，非模型缺陷——改用 global 或 n50 校准可缓解

### §10.2 校准流程定稿（用户确认 2026-08-31）：n10 > n20，反直觉结论

**四方案总对比（泛化 10 蛋白 × 5 臂 × n30）**：
| 方案 | 合计 H2 | 逐蛋白 | 说明 |
|------|:---:|------|------|
| **n10 小样本（50 条）** | **37/50 (74%)** | 1BJ4/2FEO 5/5、1AZM 3/5 | **最优** |
| n20 小样本（100 条） | 35/50 (70%) | 1AZM 5/5、**1BJ4 2/5、2FEO 4/5** | 高方差蛋白退化 |
| per-protein 诊断表 | 30/50 (60%) | 1BJ4/2FEO 0/5 | 高方差蛋白拖累 |
| big-global 兜底 | 22/50 (44%) | 陌生蛋白固有上限 | 无泄露 |

**反直觉核心发现**：小样本标定"接近诊断真值" ≠ "命中率高"。
- 1BJ4：诊断真值 slope 2.488；n10 slope 3.007（偏离最多）命中 **5/5**；n20 slope 2.747（更接近真值）反而 **2/5**
- 机制：命中率取决于校准后 target_eff 落在响应曲线弯曲的哪一段。1BJ4/2FEO 这类高方差蛋白响应弯曲（局部增益 2.0-3.3 不均），**n10 的"过度拟合"恰好把 target_eff 推到弯曲的补偿段**，n20 的"更准"反而暴露弯曲导致的系统偏移
- **结论**：小样本标定默认 n_per=10（50 条），**不要加大到 20**。加大 n_per 只压低均值噪声（治 1AZM 型 intercept 漂移），但对高方差弯曲蛋白有害
- **响应弯曲蛋白的正确解法** = LOOCV 检测 + 回退 global（n20 标定的 1AXW LOOCV=3.65 被正确标记 → 回退 global），**不是加大 n_per**

**校准流程定稿**（用户设想"大表+新蛋白小样本+自动"，数据修正后）：
```
每次生成序列：
├─ 表内（17 蛋白）→ 直接 per-protein（240 条，最稳）
├─ 表外新蛋白 → 现场小样本标定 n_per=10（50 条）
│    └─ LOOCV 大（响应弯曲）→ 自动回退 global（如实报 44%）
└─ run_guided 默认校准表 = charge_calibration_v12_2.json（自动启用）
```
2. **1BJ4/2FEO 高方差蛋白被小样本标定修复**（0/5→5/5）：n20 诊断拟合噪声大，现场 50 条拟合反而准。**之前建议的"v12.2 n50 校准表"不再需要**——现场标定直接解决
3. **⚠️ 小样本标定适用边界（1A65 反例，用户提问 2026-08-31）**：1A65 长蛋白**诊断表 5/5、小样本 0/5**——不是随机噪声，也不是采样不均匀（5 点间隔均匀=4），而是**确定性偏差**。根因=1A65 响应曲线在极端负电区剧烈弯曲（局部增益 0.30~2.62，含近似水平平台），小样本 5 点（−35/−31/−27/−23/−19）**窗口窄（仅 native±8）且恰好横跨弯曲最剧烈区段**，未覆盖正电端约束曲线形态 → 线性拟合 slope 偏大（1.60 vs 诊断 1.50）、intercept 偏正（+1.70 vs −4.33）→ target_eff 被推浅（target−35 时 −22.9 vs −20.5）→ 实际生成偏负，dev 3-3.8 全 miss。**插值预测与实测吻合**。**适用边界**：小样本标定对响应近似线性蛋白有效（2FEO 增益 1.1-2.1 均匀）；对响应明显弯曲的蛋白（长蛋白极端负电区）native±8 窗口不够，**需扩窗（含弯曲区段另一端/正电端）约束曲线**——采样点应均匀但**覆盖范围必须足够宽**
4. **slope 跨蛋白离散度大（0.80-3.01）**：正是 global 校准对陌生蛋白失效的根因；现场标定规避了这个问题
